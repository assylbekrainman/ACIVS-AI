## ACIVS-102 — Добавить валидацию входных путей и понятные ошибки
- **Тип:** bug fix
- **Приоритет:** P1
- **Проблема:** генератор в Node.js сразу делает `fs.readFileSync(DATA.logoPath)` и падает с `ENOENT`, если путь невалиден. В Python-генераторе также нужна более дружелюбная диагностика при проблемах с шаблоном.
- **Что сделать:**
  1. До чтения файла проверить существование `logoPath` (`fs.existsSync`/`fs.accessSync`) и вывести понятную ошибку с рекомендацией.
  2. Для Python-скрипта оставить текущий `FileNotFoundError`, но дополнить сообщение конкретной инструкцией по ожидаемому пути/имени шаблона.
  3. Добавить единый формат ошибок (например, префикс `INPUT_ERROR:`).
- **Затронутые файлы:**
  - `skills/dkt-letters/scripts/generate_letter_kn.js`
  - `skills/dkt-letters/scripts/gen_acivs_notice.py`
- **Критерии приёмки (DoD):**
  - При неверном `logoPath` скрипт завершает работу с человекочитаемой ошибкой (без необработанного stack trace).
  - При отсутствии шаблона в Python сообщение содержит подсказку «куда положить файл и как он должен называться».
