# ACIVS-AI — скиллы менеджера ДКТ АО «Фонд науки»

Репозиторий — набор Claude-скиллов в `skills/<имя>/SKILL.md` (карта и описание: `README.md`).
Входные точки: `acivs-navigator` (АЦИВС, сопровождение) и `dogovor-navigator` (заключение Договора).

## Общие правила для всех скиллов и документов
- Язык ответа — язык пользователя (рус / қаз / eng), по умолчанию русский.
- Даты — ДД.ММ.ГГГГ; суммы — `XXX XXX XXX,XX тенге`; БИН/ИИН — ровно 12 цифр.
- Официальные документы (.docx): Times New Roman, 14 pt, если эталон скилла не говорит иного.
  Форматирование брать из `references/formatting-spec.md` и реальных эталонов, не «по памяти».
- Каждый проект подчиняется КД **своего года**: 2024-2026, 2025-2027 или 2026-2028 (год конкурса /
  Договора, не год проверки). Лимиты, пункты и проценты берутся из КД этого цикла
  (`references/budget-limits.md`, `references/kd-clause-map.md`). Цикл неочевиден — спросить
  пользователя, не брать процент «по умолчанию».
- Цифры не додумывать: нет данных (смета, раздел заявки, Excel ФЭД) — запросить документ.
- Подписанты и исполнители — только из `references/signatories.md`.

## Правила редактирования репозитория
- Каждый `SKILL.md` начинается с frontmatter (`name`, `description` с триггерами).
- Общие справочники лежат копиями в нескольких скиллах (`budget-limits.md`, `signatories.md`).
  Менять только эталон (`acivs-knowledge` / `dkt-letters-internal`), затем
  `scripts/check_shared_refs.sh --sync`. Проверка без флага — перед каждым коммитом.
- Новый/изменённый скилл — с `evals/evals.json` (формат skill-creator) на синтетических данных.
- Реальные данные проектов (ИРН, БИН, IBAN, ФИО сотрудников, суммы) в evals и примерах не использовать.
- README обновлять при добавлении, переименовании или удалении скилла.
- Коммиты — по-русски, одно изменение на коммит.
