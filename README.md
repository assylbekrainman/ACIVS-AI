# ДЖАРВИС · АЦИВС

Голосовой ассистент на русском для проект-менеджера ДКТ АО «Фонд науки».
Основа — [adewaskar/jarvis](https://github.com/adewaskar/jarvis) (интерфейс в стиле Iron Man,
мозг — Claude Code как библиотека). Здесь он переведён на русский и подключён к 39 скиллам АЦИВС из
папки [`skills/`](skills): **сказали команду или ключевое слово — нужный скилл запускается сам**.

> «Джарвис, проверь бюджет по отчёту» → скилл `acivs-budget-check` →
> результат на панели, документ в `output/`.

Каталог скиллов и архитектура процессов — в [docs/SKILLS.md](docs/SKILLS.md).

---

## Как это работает

```
 браузер (лицо и голос)                 мост (мозг и руки)
 ┌───────────────────────────┐   ws    ┌────────────────────────────────────┐
 │ слово «Джарвис»           │◄──────► │ bridge/server.mjs                  │
 │ распознавание речи ru-RU  │  8787   │  Claude Agent SDK (= Claude Code)  │
 │ синтез речи, HUD, панели  │         │  bridge/skills.mjs ← РОУТЕР        │
 └───────────────────────────┘         │  cwd = корень репозитория          │
                                       └────────────────────────────────────┘
```

**Роутер скиллов** (`bridge/skills.mjs`). Перед отправкой команды агенту мост:

1. читает `skills/*/SKILL.md` и достаёт ключевые фразы из `description`
   («Используй ВСЕГДА когда пользователь упоминает: …»);
2. сопоставляет их с командой (без учёта падежа и порядка слов) + голосовые
   псевдонимы («сз на транш», «красные флаги», «проверь контрагента»…);
3. дописывает к запросу служебную подсказку «АВТОМАРШРУТ» с лучшими скиллами —
   агент открывает `SKILL.md` и выполняет его без лишних вопросов.

Если ключевых слов не нашлось, а задача из сферы АЦИВС — системный промпт отправляет
агента в `acivs-navigator` (отчёты и заключения) или `dogovor-navigator` (заключение договора).

Явные команды тоже работают: «скилл acivs-memo», «/escrow-fot».

Проверить роутер без голоса и Claude:

```bash
npm run skills:test                      # встроенные примеры
npm run skills:test -- "сделай СЗ на транш"
```

## Запуск

Нужны: **Claude Code** (установлен и авторизован — `claude`), **Node.js 20+**,
**Chrome или Edge** в обычном окне (во встроенных превью микрофон заблокирован).

```bash
npm install
npm start              # только чтение: поиск, анализ, панели, запись в output/
npm run start:writes   # + оболочка и файлы везде: нужно скиллам, что собирают .docx/.xlsx скриптами
```

Откройте <http://localhost:5173>, нажмите **ЗАПУСК**, разрешите микрофон и скажите
**«Джарвис»**. Клавиши: **Пробел** — говорить без слова пробуждения, **Escape** — отбой,
**V** — сменить голос, **D** — диагностика.

Рабочие файлы: входные отчёты, Excel ФЭД и сканы кладите в `input/`, готовые документы
появляются в `output/` (обе папки в `.gitignore`, в репозиторий не попадают).

## Безопасность

Наследуется от оригинала: шлюз `decideTool()` в `bridge/server.mjs` по умолчанию **только читает**.
Исключение добавлено одно: `Write`/`Edit` разрешены внутри `output/`. Всё остальное
(Bash, отправка писем, платежи, действия в браузере) — только с `npm run start:writes`.
Скиллы генерируют документы Python/Node-скриптами через Bash, поэтому для полного цикла
«команда → готовый .docx» нужен режим `start:writes`. Письма, платежи и перечисления
ассистент по промпту не отправляет без явной команды.

Данные грантополучателей обрабатываются в вашей учётной записи Claude Code; не кладите в
`input/` то, что нельзя передавать в облако Anthropic.

## Голос и язык

* Слово пробуждения: «Джарвис» (принимаются «Жарвис», «Джервис», Jarvis).
* Распознавание: браузерное `ru-RU`; при ключе `ELEVENLABS_API_KEY` — ElevenLabs Scribe с
  автоопределением языка (в том числе казахского).
* Синтез: русский голос ОС (Yuri / Pavel / Dmitry / Google русский), с ключом ElevenLabs — облачный.
* Ответ идёт на языке обращения (русский / казахский / английский). Казахская речь в браузерном
  режиме распознаётся хуже — для неё лучше ключ ElevenLabs.

Остальные настройки (`JARVIS_MODEL`, `JARVIS_EFFORT`, порт, `.env.local`) — как в оригинале,
см. `.env.example`.

## Что изменено относительно jarvis

* системный промпт моста и прямого режима — на русском, под задачи ДКТ и скиллы АЦИВС;
* `bridge/skills.mjs` — роутер скиллов; `cwd` моста — корень репозитория;
* запись в `output/` разрешена шлюзом; `scripts/route-test.mjs` — проверка роутера;
* голосовой слой: wake-word, эхо-фильтр, `ru-RU`, выбор русского голоса, реплики-заполнители;
* интерфейс: статусы, подсказки, экран загрузки, шрифт с кириллицей (Exo 2).

Не переведены: `scripts/setup.mjs` и комментарии в коде (остались на английском, как в оригинале).
