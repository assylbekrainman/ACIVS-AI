# ACIVS-AI — Скиллы для менеджера ДКТ АО «Фонд науки»

Набор специализированных AI-скиллов для автоматизации рабочих процессов  
проект-менеджера Департамента коммерциализации технологий (ДКТ) АО «Фонд науки».

Охватывает полный цикл: от приёмки отчёта грантополучателя до формирования  
заключения АЦИВС, служебных записок и официальных писем.

---

## Скиллы

| # | Скилл | Что делает |
|---|-------|-----------|
| 01 | **acivs-intake** | Принимает пакет документов ГП, классифицирует по статьям В.1–В.14 |
| 02 | **acivs-budget-check** | 8 числовых проверок: ФОТ ≤30%, аренда ≤20%, продвижение ≥5%, годовое распределение 21/57/22, софинансирование |
| 03 | **acivs-docs-check** | Чек-лист комплектности подтверждающих документов по всем 12 статьям |
| 04 | **acivs-activities** | Сверяет каждое мероприятие КП с текстом отчёта и документами |
| 05 | **acivs-financial** | Переносит данные из Excel ФЭД в Разделы 2-3 заключения |
| 06 | **acivs-red-flags** | 15 паттернов нарушений с severity/risk score, от аффилированности до наличных операций |
| 07 | **acivs-conclusion** | Формирует полное заключение АЦИВС (5 разделов, .docx) |
| 08 | **acivs-memo** | СЗ на аванс и транш с автозаполнением реквизитов |
| 09 | **acivs-monthly** | Ежемесячный мониторинг РПВ, табелей, приказов ФОТ |
| 10 | **dkt-letters** | 10 типов писем: победителям, в КН, на Правление, ИнвестКом, ГП (рус + каз) |
| 11 | **acivs-knowledge** | Справочник КД: лимиты, штрафы, сроки, термины. С reference-файлами |
| 12 | **gp-mailing** | Создаёт черновик Gmail на всех грантополучателей ДКТ-3 |
| 13 | **investkom** | Чек-лист соответствия КД + ПЗ на Инвестиционный комитет |

## Контекст

- **Конкурс**: Грантовое финансирование РННТД 2025–2027
- **Механизмы**: М1 (≥20% софин.), М2 (≥25%), М3 (≥35%)
- **Транши**: Аванс 50% → 40% → 10% (финальный после ННС)
- **Доход**: М1 ≥10%, М2-М3 ≥15% от суммы гранта к завершению
- **Штраф просрочки**: 0.1%/день × сумма этапа, max 10%
