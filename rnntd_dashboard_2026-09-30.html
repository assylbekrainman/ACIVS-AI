    Методология и определения

    Источник данных
    Только Google Drive: файлы «Показатели проектов на ДД.ММ.ГГГГ» (по одному на отчётную дату), «Перечень проектов 2022–2026 (с датами заверш.)» и «Проекты 2022–2026 г. данные». Лист «Свод» и сторонние файлы не используются, все итоги считаются по проектам.
    Перечень проектов
    Файл «Перечень проектов 2022–2026 (с датами заверш.)» на Drive даёт договор, дату завершения, регион, место реализации, частного партнёра, БИН, ДКТ, менеджера и решения ННС. Статус: «Закрыт/прекращён» — в строке есть решение ННС, отказ, прекращение или неисполнение; «Завершён» — дата завершения не позже отчётной; «В реализации» — дата позже отчётной; «Не определён» — дата не распознана. Для конкурсов 2016–2018 перечня нет — статус «Нет данных». Проверка: число незакрытых проектов сравнивается с числом «в реал.» в названии листа.
    Охват
    Все проекты, встречающиеся хотя бы в одном файле показателей или в перечне. Кириллические и латинские буквы в ИРН (А/A, Р/P) считаются одинаковыми. Отчётность: «В отчётности» — проект есть в последнем файле показателей, «Вне отчётности» — был в прежних файлах, «Нет в файлах показателей» — только в перечне.
    Показатели проекта
    Берутся из последнего файла, где проект есть. История по датам строится из значений проекта в каждом файле.
    Накопленные продажи
    Общие продажи проекта с начала реализации на отчётную дату (колонка «Общие продажи всего»).
    Грант и освоение
    Грант — сумма по договору; перечислено — фактически перечисленные средства; освоение = перечислено ÷ грант по проектам, где известны обе суммы.
    Продажи на 1 ₸ гранта
    Накопленные продажи ÷ перечисленный грант. Для поздних конкурсов показатель занижен: проекты ещё не вышли на продажи.
    Описательные поля
    Отрасль — по приоритетному направлению; если в источниках Drive отрасли нет (конкурсы 2016–2018 и часть проектов 2022–2026), она определена по названию проекта по единому справочнику tools/rnntd_industry_by_name.csv и помечена «определена по названию проекта». Тип организации — по полю «Тип организации» заявителя (файл «Проекты 2022–2026 г. данные»), приведённому к категориям: ВУЗ, НИИ, НПЦ, бизнес-организация, государственная организация, общественное объединение, физическое лицо; если поле пустое — по названию заявителя, а для конкурсов 2016–2018 — по названию грантополучателя (помечено в карточке); регион — из перечня, при его отсутствии — регион заявителя. Поля есть только у проектов конкурсов 2022–2026.
    Полнота данных
    «Полные» — заполнены отрасль, регион, сумма гранта и продажи. «Частичные» — нет хотя бы одного из этих полей. «Нет показателей» — нет ни одной финансовой метрики.
    Заявители и грантополучатели
    Заявитель — из перечня проектов 2022–2026, грантополучатель — из файлов показателей или перечня. Названия приводятся к общему виду: без кавычек, организационно-правовой формы и регистра; «им.» читается как «имени». Грантополучатели с одинаковым БИН объединяются, если их названия похожи; если по одному БИН записаны разные организации, они не объединяются и попадают в замечания.
    Справки
    Файлы формируются в браузере из выбранных данных: Word и Excel — стандартные файлы Office; PDF — страницы-изображения (текст в PDF не выделяется), для текстового PDF откройте HTML-версию и распечатайте в PDF.
    Обновление
    Раз в квартал: новый файл «Показатели проектов» добавляется в набор, скрипт tools/rnntd_sync.py формирует таблицы для панели.
    Персональные данные
    ФИО, пол, возраст и дата рождения руководителей проектов в панель не загружаются.

    Панель носит аналитический характер, не является аудиторским заключением и не заменяет проверку первичных документов.
