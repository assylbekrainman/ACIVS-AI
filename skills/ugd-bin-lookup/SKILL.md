# Поиск БИН УГД/ДГД по району регистрации

Данные — `references/ugd-registry.csv` (246 органов; источник и контроль качества — `references/SOURCE.md`).
Поиск — `scripts/ugd_lookup.py` (стандартная библиотека Python, без зависимостей).

## Как использовать

1. Определи район и область **юридической регистрации** ГП (по справке о госрегистрации / Договору /
   реквизитам ГП — не по фактическому офису). Нет данных — спроси пользователя.
2. Запусти:
   ```bash
   python3 scripts/ugd_lookup.py "Медеуский район г. Алматы"
   python3 scripts/ugd_lookup.py --bin 910740000123      # обратный поиск: чей это БИН
   python3 scripts/ugd_lookup.py --check                 # проверка контрольных цифр справочника
   ```
3. Код возврата и действия:
   - `0` — найдена ровно одна запись: перенеси БИН и наименование **как есть** (например
     «УГД по Медеускому району», БИН 910740000123);
   - `3` — несколько кандидатов: покажи пользователю список и **спроси**, какой район; не выбирай сам;
   - `2` — не найдено: уточни район/область; **не подставляй** БИН из чужого письма или из памяти.
4. В строках ИПН и Соцналога БИН и наименование налогового органа **одинаковые**; различаются
   только КБК (101201 ИПН / 103101 Соцналог) — см. `escrow-fot/references/shared/tax-beneficiaries.md`.

## Постоянные реквизиты получателя-банка

Одинаковы для любого УГД (из шапки кодификатора): ГУ «Комитет казначейства Министерства финансов РК»,
БИК `KKMFKZ2A`, ИИК `KZ24070105KSN0000000`. Меняются только БИН и наименование органа.

## Правила и ограничения

- Справочник — по состоянию на **2025 год**. Органы реорганизуются (новые районы, области Жетісу, Абай,
  Ұлытау уже включены) — при сомнении или если района нет в справочнике, сверь с актуальным
  кодификатором на kgd.gov.kz / data.egov.kz и скажи об этом пользователю.
- Для городов республиканского значения (Алматы, Астана, Шымкент) органы — районные УГД; «ДГД по
  области/городу» — областной уровень, получателем платежа ГП обычно выступает районное УГД.
- **Известная ошибка эталонных писем:** БИН `910740000123` — УГД по Медеускому району г. Алматы; он
  встречается в письмах БЦК и Alatau (2026) как получатель Соцналога для ГП из других районов.
  Если у ГП не Медеуский район — это ошибка, исправь по справочнику.
- Скилл отвечает только на вопрос «какой БИН у налогового органа». Суммы, КБК и бланки — в `escrow-fot`.
