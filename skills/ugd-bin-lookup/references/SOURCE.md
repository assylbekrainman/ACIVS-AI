# Источник справочника УГД/ДГД

`ugd-registry.csv` — «Справочник (кодификатор) с указанием БИН и реквизитами для зачисления
платежей в бюджет по органам государственных доходов (налоговых органов) РК
(по состоянию на 2025 год)». Колонки: `region` (раздел кодификатора), `code` (код УГД для
зачисления в бюджет), `bin` (БИН бенефициара), `name` (наименование бенефициара).

- Взято из текста документа на prg.kz (doc_id=30433189), 246 записей; независимо сверено
  с копией на mybuh.kz (240 БИН совпали, 6 — новые образования, которых нет во второй копии).
- Официальный первоисточник — КГД МФ РК (kgd.gov.kz) и портал открытых данных (data.egov.kz);
  с облачной среды kgd.gov.kz недоступен, API data.egov.kz требует ключ.
- Контроль качества: все 246 БИН проходят проверку контрольной цифры (`scripts/ugd_lookup.py --check`);
  пять БИН из реальных эскроу-расписок (Медеу, Бостандык, Карасай, Айыртау, Шардара) совпали.
- Разделы «г.Нур-Султан» = г. Астана (прежнее название в кодификаторе).
- Реквизиты Комитета казначейства (получатель-банк для всех УГД, из шапки кодификатора):
  БИК `KKMFKZ2A`, ИИК `KZ24070105KSN0000000`, ГУ «Комитет казначейства Министерства финансов РК».

Обновлять при выходе новой редакции кодификатора (реорганизация УГД, новые районы):
заменить CSV и прогнать `python3 scripts/ugd_lookup.py --check` и тесты.
