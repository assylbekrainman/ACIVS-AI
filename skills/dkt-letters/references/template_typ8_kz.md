### ТИП 8: ХАТТ ҒЫЛЫМ КОМИТЕТІНЕ — ШЫҒЫСТАР СМЕТАСЫНА ӨЗГЕРІСТЕР
**Когда:** ГП просит изменить смету расходов.
**Язык:** ТЕК ҚАЗАҚ ТІЛІНДЕ (только на казахском, без русской версии).
**Подписант:** Басқарма Төрағасы.

**Толық үлгі (word-for-word шаблон):**

**ШАПКА:**
```
№ ___ / дата

010000, Астана қаласы, Тәуелсіздік даңғылы 41
тел +7(7172) 575 003, www.science-fund.kz

Қазақстан Республикасы
Ғылым және жоғары
білім министрлігінің
Ғылым комитеті
```

**1-АБЗАЦ — НЕГІЗ:**
```
«Ғылыми және (немесе) ғылыми-техникалық қызмет нәтижелерін коммерцияландыру»
ғылыми және (немесе) ғылыми-техникалық қызметті дамытудың басым бағыты бойынша
Ұлттық ғылыми кеңестің (бұдан әрі – ҰҒК) [хаттама шешімі: №N мерзімі] хаттамалық
шешімінің негізінде «Ғылым қоры» АҚ (бұдан әрі – Қор) [ИРН] «[жоба атауы]» жобасы
(бұдан әрі – Жоба) бойынша Грант алушы – [ГП атауы] ғылыми және (немесе)
ғылыми-техникалық қызмет нәтижелерін коммерцияландыруға грант беру туралы
[шарт күні] №[шарт №] шартты (бұдан әрі – Шарт) жасасты.
```

**2-АБЗАЦ — ГП ӨТІНІШІ:**
```
Грант алушы Қорға [хат күні] [хат №] хатпен Шарттың Қосымша 2
(Шығыстар сметасы) қосымшасына өзгерістер енгізу жөнінде өтінішпен жүгінді.
```

**3-АБЗАЦ — ҚАЖЕТТІЛІК НЕГІЗДЕМЕСІ** (жағдайға қарай біреуін таңдау):

МРП өзгерісі жағдайы:
```
Шартқа өзгерістер енгізу қажеттілігі 2026 жылға МРП-ның жаңа мөлшерінің
бекітілуіне байланысты шығыстар сметасының тармақтарын нақтылау және
қайта бөлу қажеттілігінен туындайды, сонымен қатар грант және қосымша
қаржыландырудың жалпы көлемі сақталады.
```

Жобаның нақты барысы жағдайы:
```
Шартқа өзгерістер енгізу қажеттілігі жобаның нақты іске асырылу барысы,
өндірістік технологияның схемасының модификациясы және қаражат үнемдеуі
жағдайында шығыстар сметасының тармақтарын нақтылау және қайта бөлу
қажеттілігінен туындайды, сонымен қатар грант және қосымша қаржыландырудың
жалпы көлемі сақталады.
```

**4-АБЗАЦ — СҰРАНЫС (өзгертпей):**
```
Жоғарыда аталғандарды ескере отырып және Қазақстан Республикасы Ғылым
және жоғары білім министрінің 2023 жылғы 25 қыркүйектегі №487 бұйрығымен
бекітілген Ұлттық ғылыми кеңестердің тізбесі мен ережесінің 3-тарауының
21-тармағының 10) тармақшасына сәйкес, Шарттың Қосымша 2 (Шығыстар сметасы)
қосымшасына өзгерістер енгізу жөніндегі Грант алушының өтінішін шешім
қабылдау үшін Ұлттық ғылыми кеңес қарауына шығаруды сұраймыз.
```
