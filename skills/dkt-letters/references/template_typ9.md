### ТИП 9: ПИСЬМО В КН ПО АЦИВС (аралық/қорытынды есеп бойынша ҒК хат)
**Когда:** АЦИВС завершён, нужно направить промежуточный или итоговый отчёт
в Комитет науки для рассмотрения ННС и принятия решения о финансировании.
**Триггер:** «письмо в КН», «аралық есеп бойынша ҒК хат», «передать отчёт на ННС»,
«письмо в КН по АЦИВС», «финансирование следующего этапа», «вынести на ННС промотчёт»,
«недостача со-финансирования КН», «со-финансирование письмо в КН».
**Язык:** двуязычный (казахский + русский, оба блока в одном документе).
**Подписант:** Председатель Правления / И.о. Председателя Правления.

**Источники данных (извлечь из прикреплённых файлов):**
- АЦИВС → сумма экономии, название банка эскроу, дата заключения, этап
- Договор (стр.1) → №, дата, ИРН, название проекта, ГП, решение ҰҒК/ННС из преамбулы
- ДС → номера и даты всех допсоглашений
- Переписка → номер и дата уведомления Фонда, номер и дата ответа ГП (при недостаче)

**Фиксированные реквизиты:**
- Исполнитель: Снадин А.А., тел. 8-7172-57-50-15 / 1201
- Подписант: Председатель Правления Ашкин А.А.

**Важные правила оформления:**
- Исходящий номер письма — НЕ включать (проставляется в Documentolog)
- Эскроу: только название банка (напр. «Alatay City bank»), без номера счёта KZ
- Если экономия = 0 — абзац про эскроу не включать вообще
- Если нет ДС — в Приложениях только отчёт + АЦИВС + Договор

**Генерация .docx:**
Использовать скрипт `scripts/gen_kn_letter.py`. Заполнить блок ПАРАМЕТРЫ ПРОЕКТА
и установить `SOFIN_SHORTFALL = True/False`. Запустить:
```
pip install python-docx --break-system-packages --quiet
python scripts/gen_kn_letter.py
```

#### СТРУКТУРА ПИСЬМА (стандарт — без недостачи со-финансирования, 5 абзацев)

| # | Содержание |
|---|------------|
| П1 | Основание (ННС, Договор) + реквизиты проекта |
| П2 | Предоставление промежуточного отчёта за N-й этап |
| П3 | Итоги АЦИВС: мероприятия выполнены + экономия (если > 0) |
| П4 | Ссылка на Приказ №487 пп.8) п.20 гл.3 — задачи ННС |
| П5 | Просьба вынести на ННС отчёт и заключение АЦИВС |

**Приложения (без ДС и без недостачи):**
1. промежуточный отчёт за N-й этап;
2. заключение АЦИВС от [дата];
3. Договор [реквизиты].

#### ВАРИАНТ С НЕДОСТАЧЕЙ СО-ФИНАНСИРОВАНИЯ (7 абзацев + хронология)

Если АЦИВС выявил неисполнение обязательств по со-финансированию — добавить
два дополнительных абзаца между П3 и П4 (стандартные):

| # | Содержание |
|---|------------|
| П1 | Основание (ННС, Договор) + реквизиты проекта |
| П2 | Предоставление промежуточного отчёта за N-й этап |
| П3 | Итоги АЦИВС: мероприятия + экономия |
| **П4** | **Блок со-финансирования:** ссылки на пункты Договора (вложение на р/с + расходование исключительно на цели) + выявленная недостача [план → факт → дельта] |
| **П5** | **Хронология:** уведомление Фонда №[X] от [дата] → ответ ГП №[Y] от [дата] + документы + выписка |
| П6 | Ссылка на Приказ №487 пп.8) п.20 гл.3 — задачи ННС |
| П7 | Просьба вынести на ННС отчёт и заключение АЦИВС |

**Параметры блока со-финансирования (уточнить из Договора ГП):**
- `CLAUSE_SOFIN_DEPOSIT`  — пункт об обязательстве вложить средства на р/с
- `CLAUSE_SOFIN_SPENDING` — пункт о расходовании исключительно на цели Проекта
- `SOFIN_ACCOUNT` — номер счёта со-финансирования (№KZ...)
- `SOFIN_PLAN` / `SOFIN_DEFICIT` / `SOFIN_DEFICIT_RU` / `SOFIN_DEFICIT_KZ`
- `FOND_NOTICE_NO` / `FOND_NOTICE_DATE` — реквизиты уведомления Фонда
- `GP_RESP_NO` / `GP_RESP_DATE` — реквизиты ответа ГП

**Дополнительные приложения (при недостаче):**
- документы, подтверждающие исполнение обязательств по со-финансированию
  (ГП письмо исх. [номер] от [дата]);
- выписка о движении средств по счёту со-финансирования с отметкой банка.

**Имя файла:** `Письмо_КН_[ИРН]_[этап]этап.docx` — сохранить в папку ГП.
