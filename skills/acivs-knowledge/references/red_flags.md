# Красные флаги — расширенный контекст (acivs-knowledge)

> **Канонический список — в скилле `acivs-red-flags`.** Там 15 флагов с
> формулой проверки, severity, правовым основанием и risk-score — это
> основной источник при формальной проверке отчёта. Этот файл больше не
> дублирует эти 15 паттернов отдельным параллельным списком (как было
> раньше — с риском разойтись в цифрах). Он теперь состоит из двух частей:
> (A) таблица соответствия для быстрой навигации из справочника в нужный
> флаг, и (B) паттерны, которых в тех 15 флагах нет — используй их вместе
> с `acivs-docs-check` и `acivs-activities`, а не вместо `acivs-red-flags`.
>
> Числовые пороги (проценты лимитов, доля софинансирования) не
> продублированы здесь отдельно — единый источник `references/budget-limits.md`.

## Часть A — соответствие категориям acivs-red-flags

| О чём вопрос менеджера | Флаг(и) acivs-red-flags |
|---|---|
| Расходы из гранта на запрещённые статьи / командировки из гранта / оплата СН-СО-ОСМС из гранта | Флаги 2, 3, 15 |
| Наличные операции по эскроу-счёту | Флаг 10 |
| Превышение лимита по статье (ФОТ/аренда/продвижение) | См. `references/budget-limits.md`, проверка формулой — `acivs-budget-check` |
| Перераспределение между статьями > 10% | Флаг 6 |
| Софинансирование ниже нормы | Флаг 5 |
| Аффилированность поставщика | Флаг 1 |
| Б/у оборудование / нет логотипа Фонда на оборудовании | Флаги 4, 12 |
| Руководитель проекта не на полном рабочем дне | Флаг 7 |
| Просрочка предоставления отчёта | Флаг 8 |
| Доход ниже требуемой траектории (10%/15% от гранта) | Флаг 11 |
| Доверенность датирована позже накладной / нет номера проекта в преамбуле договора | Флаги 13, 14 |
| Участие члена группы больше чем в 2 проектах | Флаг 9 (в этом файле раньше не было — добавлено при сверке) |

## Часть B — паттерны, которых нет в acivs-red-flags

Используй вместе с `acivs-docs-check` (комплектность документов) и
`acivs-activities` (верификация мероприятий КП) — это не про финансовые
нарушения, а про качество и полноту самого отчёта.

### Проектная группа — общие требования (не про руководителя, см. Часть A)
- Менее 4 человек в группе
- Члены группы без высшего образования
- Члены группы не граждане/резиденты РК
- Отсутствие трудовых договоров

### Проблемы с документами
- Договоры без реквизитов эскроу-счёта
- Отсутствие ЭСФ при наличии платёжных поручений
- Расхождение сумм: договор ≠ акт ≠ платёжное поручение

### Структурные проблемы отчёта
- Отсутствие количественных данных в «достигнутых результатах»
- Мероприятие КП не отражено в Основной части отчёта
- Нет ссылок на фото/видео в тексте отчёта
- Отчёт не прошит / не пронумерован / без печати

### Временны́е несоответствия (кроме самой просрочки — см. Флаг 8)
- Даты работ/услуг выходят за рамки этапа
- Даты платёжных поручений позже окончания этапа

### Эффективность проекта (кроме дохода — см. Флаг 11)
- Не созданы заявленные рабочие места
- Нет патентной активности (заявки, патенты)
- Отставание от плана по производству продукции

### Недостающие документы
- Неполный комплект по любой статье (детальный чек-лист — `acivs-docs-check`)
- Отсутствие банковских выписок (В.13, В.14)
- Нет сопроводительного письма
- Не зарегистрировано в ИС НЦ ГНТЭ

## Типичные ошибки грантополучателей (практика, без прямого флага)

1. Путают грантовые и софинансируемые расходы
2. Не размещают логотип Фонда на оборудовании (см. также Флаг 12)
3. Забывают предоставить табели за каждый месяц
4. Не регистрируют отчёт в ИС НЦ ГНТЭ
5. В реферате нет сумм по годам
6. В заключении отчёта нет информации о доходах и ОИС
7. Мероприятия КП описаны обобщённо, без количественных показателей

*(Пункты про командировки из гранта, доверенность позже накладной и
номер проекта в преамбуле убраны отсюда — раньше повторялись дважды в
этом файле; теперь один раз, в Части A/B выше.)*

## Формат вывода при проверке

При выявлении красного флага, формируй запись:

```
[УРОВЕНЬ] [СТАТЬЯ/РАЗДЕЛ]: Описание нарушения
  Основание: ссылка на пункт КД / правило (или номер флага acivs-red-flags)
  Рекомендация: что запросить / как исправить
```
