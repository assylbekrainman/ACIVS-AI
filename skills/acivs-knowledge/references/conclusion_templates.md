## 2. Заключение АЦИВС по итоговому (заключительному) отчёту

Отличия от промежуточного:
- **Шапка**: «Утверждено Решением Правления АО «Фонд науки» №___ от «___» ________20___года»
- **Раздел 5 (Выводы)** содержит дополнительно:
  - Ожидаемые результаты по п. 1.3 Договора (перечислить все с указанием достигнуто/нет)
  - Объём доходов: «не менее 10%(15%) от суммы гранта, а именно [СУММА] тенге»
  - Детальная информация по эффективности за весь период:
    - Запланированное/фактическое количество продукции
    - Объём реализации (внутренний рынок + экспорт)
    - Охранные документы (заявки, патенты)
    - Лицензионные соглашения
    - Количество созданных рабочих мест
    - Привлечённые инвестиции

## 3. Инструкции по заполнению

### Входные данные для генерации заключения:

| Поле | Описание | Пример |
|---|---|---|
| type | промежуточное / итоговое | промежуточное |
| grantee_name | Наименование грантополучателя | ТОО «Инновация» |
| irn | ИРН проекта | DP2369-0045 |
| project_name | Наименование проекта | Разработка биосенсоров |
| contract_number | Номер договора | 125 |
| contract_date | Дата договора | 15.03.2025 |
| stage_number | Номер этапа | 1 |
| stage_duration | Длительность этапа (мес.) | 12 |
| grant_amount | Сумма гранта этапа (тенге) | 50 000 000 |
| cofinancing_amount | Сумма софинансирования (тенге) | 15 000 000 |
| actual_payments | Фактические выплаты по гранту | 48 500 000 |
| savings | Экономия | 1 500 000 |
| unplanned_use | Незапланированное использование | 0 |
| escrow_balance | Остаток на эскроу-счёте | 1 500 000 |
| return_amount | Сумма к возврату | 1 500 000 |
| cofinancing_percent | % исполнения софинансирования | 100 |
| has_nds | НДС / без НДС | без НДС |
| violations | Описание нарушений (если есть) | — |
| recommendations | Рекомендации | Принять |

### При генерации .docx файла:
- Использовать шрифт Times New Roman, 12pt
- Межстрочный интервал 1.0–1.15
- Таблицы с границами
- Поля для подписей выровнены
- Формат даты: ДД.ММ.ГГГГ
- Суммы с разделителями тысяч: 50 000 000,00 тенге
