## Финансовые термины

| Термин | Описание | Значение |
|---|---|---|
| Эскроу-счёт | Специальный банковский счёт для грантовых средств | Все расходы из гранта — только через него |
| Софинансирование | Вклад ГП / частного партнёра | ≥ 20/25/35% в зависимости от механизма |
| Транш | Часть грантовых средств | 50% → 40% → 10% |
| Аванс | Первый транш (50% от этапа) | После справки БВУ о 50% софинансирования |
| ФОТ | Фонд оплаты труда | ≤ 30% от суммы гранта |
| БВУ | Банк второго уровня | Выдаёт справки для траншей |

## Участники проекта

| Термин | Описание |
|---|---|
| Грантополучатель (ГП) | Юрлицо, заключившее договор с ФН |
| Руководитель проекта (РП) | Глава проектной группы, полный рабочий день у ГП |
| Частный партнёр (ЧП) | Компания-партнёр, участвует в софинансировании |
| Проектная группа | 4–6 человек, все с высшим образованием, граждане/резиденты РК |
| Стартап-компания | Новое юрлицо, создаваемое для реализации проекта |

## Три механизма реализации

| Механизм | Софинансирование | Доход | Описание |
|---|---|---|---|
| 1 | ≥ 20% | ≥ 10% | ГП самостоятельно |
| 2 | ≥ 25% | ≥ 15% | ГП + ЧП (софинансирование) |
| 3 | ≥ 35% | ≥ 15% | ГП + ЧП (софинансирование + мат-тех база) |

## Важные примечания

- Все финансовые лимиты (ФОТ ≤30%, аренда ≤20%, продвижение ≥5%, распределение 21/57/22%) — юридически обязательны
- «КД» = Конкурсная документация РННТД 2025–2027, утв. Правлением ФН №22 от 03.09.2024
- Все расходы из гранта — только через эскроу-счёт безналичным способом
- Наличные операции — нарушение
- ИИ-система ACIVS-AI — ассистент менеджера. Финальное решение всегда за менеджером Фонда
