## 1. Виды отчётов

| Тип отчёта | Когда | Кому |
|---|---|---|
| Аннотационный отчёт | После освоения 50% средств этапа | Фонд науки |
| Промежуточный отчёт | По завершении каждого этапа (1, 2, 3) | Фонд науки → ННС |
| Итоговый (заключительный) отчёт | По завершении всего проекта | Фонд науки → ННС → Правление |
| Отчёт по эффективности | Ежеквартально (Приложение 4) | Фонд науки |
| Постгрантовый отчёт | Каждые полгода, 3 года после завершения | Фонд науки |

Всего один проект генерирует до 16+ отчётных циклов.

## 2. Структура промежуточного/итогового отчёта (Приложение 3 к Договору)

### Обязательные разделы:
1. **Титульный лист** — полное наименование организации, ИРН, подпись РП, печать
2. **Список исполнителей (проектная группа)** — 4–6 человек с подписями и указанием выполняемых разделов
3. **Содержание**
4. **Реферат** — ключевые слова (5–15), объём отчёта, общая информация с суммами по годам
5. **Введение** — цели и задачи текущего этапа; в заключительном — перечень всех промежуточных отчётов
6. **Основная часть** — описание работ по КАЖДОМУ мероприятию Календарного плана:
   - Мероприятие X.X «Наименование»
   - Ожидаемый результат по КП: ___
   - Достигнутый результат: ___ (с количественными данными!)
7. **Заключение** — анализ результатов, объём доходов, статус ОИС/патентов

## 3. Аннотационный отчёт

Предоставляется как приложение к Акту выполненных работ. Содержит:
- Наименование грантополучателя
- ИРН проекта (формат DP2369-XXXX)
- Наименование проекта
- Регистрационный номер и дата договора
- Наименование частного партнёра (при наличии)
- Суммы: софинансирование этапа, выделенный транш, аванс
- Дата предоставления отчёта
- Таблица мероприятий: Мероприятие КП → Достигнутые результаты → Примечание (подтверждающие документы)

Подписывается: Руководитель организации + Руководитель проекта (М.П.)

## 4. Отчёт по эффективности (Приложение 4 к Договору)

Ежеквартальный отчёт, включающий:
- Количество производимой продукции / оказываемых услуг (план vs факт)
- Объём реализации (внутренний рынок + экспорт) в тенге
- Охранные документы (заявки, патенты)
- Лицензионные соглашения
- Количество рабочих мест

## 5. Сроки предоставления отчётов

| Тип | Срок | Отсчёт от |
|---|---|---|
| Промежуточный | ≤ 10 рабочих дней | Завершение отчётного этапа |
| Итоговый | ≤ 15 рабочих дней | Подписание заключения АЦИВС завершающего этапа |
| Аннотационный | По мере освоения 50% | После использования аванса |

## 6. Требования к оформлению

- Отчёт на бумажном + электронном носителе
- Сопроводительное письмо обязательно
- Отчёт прошит и скреплён бумажной пломбой
- Запись о количестве прошитых и пронумерованных листов
- Подпись уполномоченного лица с расшифровкой
- Оттиск печати (при наличии)
- Промежуточный отчёт также регистрируется через ИС АО «НЦ ГНТЭ»: https://is.ncste.kz/
- При предоставлении фото/видеоматериалов — ссылки в тексте + отдельно на электронном носителе

## 7. Штрафные санкции за просрочку

Конкретные размеры штрафов определяются Договором. Менеджер обязан:
- Фиксировать дату получения отчёта
- Рассчитать наличие/отсутствие просрочки
- При просрочке — инициировать начисление штрафных санкций
- Уведомить грантополучателя в письменной форме
