# Перечень подтверждающих документов по статьям Сметы расходов

*При необходимости АО «Фонд науки» имеет право запросить дополнительные документы.*

---

## Статья 1. ФОТ согласно штатному расписанию (грант/софин)

- [ ] Копия утверждённого штатного расписания
- [ ] Копии индивидуальных трудовых договоров (на каждого члена группы)
- [ ] Табели учёта рабочего времени за отчётный период (за каждый месяц)
- [ ] Копия приказа о выходе на работу в выходные/праздничные дни + согласие работника (при наличии)
- [ ] Копия письма согласования замены члена проектной группы (при наличии)
- [ ] Расчётные ведомости з/п с указанием: ИПН, ОПВ, СО, СН, ОСМС
- [ ] Платёжные поручения с отметкой банка: з/п, ИПН, ОПВ (БЕЗ СН, СО, ОСМС — они НЕ из гранта)

**Красный флаг**: оплата СН/СО/ОСМС из средств гранта — нарушение!

## Статья 2. Закуп нового оборудования и(или) ПО (грант/софин)

- [ ] Договоры поставки (по ГК РК, с реквизитами эскроу-счёта, номер проекта в преамбуле)
- [ ] Копии счетов-фактур (ЭСФ)
- [ ] Накладные на отпуск товаров + доверенности (дата доверенности ≤ дата накладной!)
- [ ] Акты приёма-передачи (при наличии)
- [ ] Акты ввода в эксплуатацию (при наличии)
- [ ] Платёжные поручения с отметкой банка
- [ ] **ФОТО оборудования с логотипом АО «Фонд науки»**
- [ ] Паспорт на оборудование / сертификат на ПО
- [ ] Документ гарантийного сервисного обслуживания / договор ИТС

**Красный флаг**: б/у оборудование, поставщик = аффилированное лицо, нет логотипа Фонда

## Статья 3. Подготовка производственных помещений (грант/софин)

- [ ] Договоры оказания услуг/выполнения работ (по ГК РК, эскроу, номер проекта)
- [ ] Платёжные поручения с отметкой банка
- [ ] Счета-фактуры, акты выполненных работ
- [ ] Копии лицензий (если лицензируемые виды работ)

## Статья 4. Закуп расходных материалов и комплектующих (грант/софин)

- [ ] Договоры поставки (по ГК РК, эскроу, номер проекта)
- [ ] Платёжные поручения с отметкой банка
- [ ] Счета-фактуры, накладные + доверенности (дата доверенности ≤ дата накладной!)
- [ ] Акты приёма-передачи (при наличии)

## Статья 5. Оплата работ и услуг третьих лиц (грант/софин)

- [ ] Договоры оказания услуг/выполнения работ (по ГК РК, эскроу, номер проекта)
- [ ] Платёжные поручения с отметкой банка
- [ ] Счета-фактуры, акты выполненных работ
- [ ] Для физлиц: резюме, диплом квалификации (при наличии)
- [ ] Отчёты о проделанной работе (проектно-сметная документация, маркетинговый анализ и т.д.)

## Статья 6. Аренда помещений, оборудований (грант/софин)

- [ ] Договоры аренды (площадь, количество оборудования, стоимость в месяц, по ГК РК, эскроу, номер проекта)
- [ ] Документы, подтверждающие право сдачи в аренду (право собственности или договор аренды с правом субаренды)
- [ ] Платёжные поручения с отметкой банка
- [ ] Счета-фактуры, акты выполненных работ

**Лимит**: ≤ 20% от суммы гранта

## Статья 7. Защита интеллектуальной собственности (грант/софин)

- [ ] Договоры оказания услуг / счета на оплату
- [ ] Платёжные поручения с отметкой банка
- [ ] Счета-фактуры, акты выполненных работ
- [ ] Копия заявки на патент / патент / статьи / монографии

## Статья 8. Командировочные расходы (**ТОЛЬКО софинансирование!**)

- [ ] Приказы о командировании
- [ ] Командировочные удостоверения
- [ ] Платёжные поручения с отметкой банка
- [ ] Авансовые отчёты
- [ ] Проездные билеты (авиа/ж.д.), посадочные талоны, документы об оплате
- [ ] Отметки о прибытии/убытии (при наличии)

**КРИТИЧНО**: Любая оплата командировок из гранта — прямое нарушение! Только софинансирование.

## Статья 9. Затраты по продвижению продукта/услуги на рынок (грант/софин)

- [ ] Договоры (по ГК РК, эскроу, номер проекта)
- [ ] Платёжные поручения с отметкой банка
- [ ] Счета-фактуры, акты выполненных работ
- [ ] Подтверждающие материалы (ссылки на рекламу, фото стендов, сертификаты участия)

**Лимит**: ≥ 5% от суммы гранта (обязательный минимум!)

## Статья 10. Налоговые обязательства и обязательные платежи (грант/софин)

- [ ] Платёжные поручения с отметкой банка об уплате налогов
- [ ] Расчёт налоговых обязательств

**Примечание**: Из гранта — только ИПН, ОПВ. СН, СО, ОСМС — НЕ из гранта.

## Статья 11. Операционные расходы (грант/софин)

- [ ] Договоры (по ГК РК, эскроу, номер проекта)
- [ ] Платёжные поручения с отметкой банка
- [ ] Счета-фактуры, акты

**Примечание**: Коммунальные услуги, канцелярия, услуги связи — НЕ из гранта (п. 37 КД)

## Статья 12. Прочие софинансируемые затраты (только софин)

- [ ] Документы в зависимости от вида затрат
- [ ] Платёжные поручения, акты, счета-фактуры

## Банковские выписки (Приложения В.13 и В.14)

- [ ] **В.13**: Выписка о движении денег по эскроу-счёту с отметкой банка за отчётный период
- [ ] **В.14**: Выписка о движении денег по счёту софинансирования с отметкой банка

**Проверить**: нет наличных операций, целевое использование, соответствие остатков.

---

## Универсальные требования к договорам

Каждый договор закупки/услуг должен содержать:
1. Оформление по ГК РК
2. Реквизиты **эскроу-счёта** в разделе реквизитов
3. **Номер и наименование проекта** в преамбуле договора
4. Надлежащие подписи сторон и печати
