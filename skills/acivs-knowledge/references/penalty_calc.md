## 1. Штраф за просрочку сдачи отчёта

### Формула

```
Штраф = 0.1% × Сумма_этапа × Дней_просрочки
```

- **Сумма_этапа** — размер гранта за проверяемый этап (тенге)
- **Дней_просрочки** — календарные дни с дедлайна по фактическую дату подачи
- **Дедлайн** — 10 рабочих дней после окончания этапа
- **Максимальный штраф** — 10% от суммы неисполненных обязательств (п. 6.4 Договора); для итогового отчёта ставка 0,1% считается от суммы гранта (п. 6.4); за отчёт по анализу эффективности — не более 10% суммы гранта (п. 6.5)

### Пример расчёта

| Параметр | Значение |
|---|---|
| Сумма этапа | 50 000 000 тенге |
| Дедлайн | 10.04.2026 |
| Дата подачи | 25.04.2026 |
| Просрочка | 15 дней |
| Штраф (0.1% × 50М × 15) | **750 000 тенге** |
| Максимум (10%) | 5 000 000 тенге |
| Итоговый штраф | **750 000 тенге** (не превышает макс.) |

### Как посчитать дни просрочки

```python
from datetime import date

deadline = date(2026, 4, 10)
submitted = date(2026, 4, 25)
days = (submitted - deadline).days  # = 15
```

## 2. Штраф за нецелевое использование средств

### Формула

```
Штраф = Сумма_нецелевого × 3
```

- Применяется если расходы признаны нецелевыми (запрещённые категории, аффилированность и т.д.)
- ⚠ Множитель ×3 и ссылка «п. 14.1 КД» в тексте КД и Договора 2025–2027 не найдены. По п. 3.8 Договора факт нецелевого использования (по АЦИВС) — основание для истребования всех ранее перечисленных средств гранта и требования штрафа (пени). Размер штрафа уточнить у руководства до применения.

### Пример

| Параметр | Значение |
|---|---|
| Нецелевые расходы | 500 000 тенге |
| Штраф (×3) | **1 500 000 тенге** |

## 3. Штраф за недостижение показателей дохода

### Условие применения

Если по итогам проекта доход ниже нормы:
- Доход < 15% от суммы гранта (п. 55 КД, п. 2.10(26) Договора; для всех механизмов)
- ⚠ Прежний порог «10% для Механизма 1» в КД и Договоре не найден

### Формула

```
Штраф = (Норматив_дохода - Факт_дохода) × 0.5
```

- ⚠ Формула (норма − факт) × 0,5 и ссылка «п. 9.4 КД» не подтверждаются: п. 9.4 Договора — расторжение по решению суда. По тексту Договора за недостижение объёма продукции/дохода (п. 2.10(26)) — штраф 0,1% суммы гранта за каждый день неисполнения, не более 10% суммы гранта (п. 6.9). Применимую формулу уточнить.

### Пример

| Параметр | Значение |
|---|---|
| Сумма гранта | 100 000 000 тенге |
| Механизм | 2 (норма ≥ 15%) |
| Норматив дохода | 15 000 000 тенге |
| Фактический доход | 8 000 000 тенге |
| Разница | 7 000 000 тенге |
| Штраф (×0.5) | **3 500 000 тенге** |

## 4. Неустойка за нарушение сроков перечисления средств (Фондом)

> Применяется ТОЛЬКО если Фонд нарушил сроки — не для ГП.  
> 0.01% в день от суммы просроченного платежа.

## 7. Калькулятор в одну строку (Python)

```python
# Штраф за просрочку
def penalty_late(stage_sum, days_overdue):
    raw = stage_sum * 0.001 * days_overdue
    return min(raw, stage_sum * 0.10)

# Пример: этап 80 млн, просрочка 8 дней
print(f"{penalty_late(80_000_000, 8):,.0f} тенге")  # → 640,000 тенге
```
