# Пошаговый алгоритм АЦИВС

АЦИВС = Анализ целевого использования выделенных средств — основная контрольная процедура менеджера.

---

## Этап 1: Приём документов

1. Получить пакет документов от грантополучателя (бумажный + электронный носитель)
2. Проверить наличие **сопроводительного письма**
3. **Зафиксировать дату получения** (для расчёта сроков и штрафов)
4. Проверить комплектность: все приложения (А, Б, В, В.1–В.14, Г) присутствуют
5. Проверить: отчёт прошит, пронумерован, подписан, скреплён печатью

## Этап 2: Проверка структуры отчёта

1. Все обязательные разделы присутствуют: Титульный лист → Список исполнителей → Реферат → Введение → Основная часть → Заключение → Приложения
2. Состав проектной группы: 4–6 человек, подписи, указание разделов
3. Для **каждого** мероприятия Календарного плана есть отдельный раздел в Основной части
4. Для каждого мероприятия: ожидаемый результат (по КП) + достигнутый результат (с количественными данными)
5. В Заключении: информация о доходах, ОИС, патентах, лицензиях

## Этап 3: Проверка бюджета

1. Сверить Смету расходов (Прил. Б) с Отчётом о расходовании (Прил. В)
2. Рассчитать ФОТ как % от суммы гранта → **лимит ≤ 30%**
3. Рассчитать аренду как % от суммы гранта → **лимит ≤ 20%**
4. Проверить расходы на продвижение → **минимум ≥ 5%**
5. Проверить распределение по годам → **21% / 57% / 22%**
6. Выявить перераспределение между статьями → **≤ 10% без согласования**
7. Проверить отсутствие **запрещённых расходов** (п. 37 КД)
8. Проверить: командировки (ст. 8) оплачены **только** из софинансирования
9. Проверить софинансирование: фактическое ≥ установленного % по механизму
10. Рассчитать: экономию, незапланированные расходы, остаток на эскроу

## Этап 4: Проверка подтверждающих документов

Для каждой статьи расходов — проверить полный комплект по чек-листу (см. `supporting_docs_checklist.md`).

### Ключевые кросс-проверки:
- Каждая строка сметы имеет корреспондирующее мероприятие в Календарном плане
- Суммы в платёжных поручениях соответствуют суммам в договорах и актах
- Даты документов логически согласованы (договор → счёт → оплата → акт)
- Реквизиты эскроу-счёта во всех договорах
- Номер и наименование проекта в преамбуле всех договоров
- Банковские выписки (В.13, В.14) подтверждают движение средств

## Этап 5: Формирование заключения АЦИВС

### Структура заключения (5 разделов):
1. **Общая информация** — наименование, ИРН, договор, этап, суммы
2. **График освоения средств** — план vs факт по транша́м
3. **АЦИВС по освоению средств** — постатейный анализ расходов
4. **АЦИВС по выполнению мероприятий** — по каждому пункту КП
5. **Выводы** — итоги по гранту, софинансированию, рекомендации

### Подписи заключения:
- **Составил**: Менеджер / уполномоченное лицо
- **Проверил**: Старший бухгалтер / бухгалтер / экономист ФЭД
- **Согласовано**: Директор ДКТ №1/№2, Управляющий директор, Главный бухгалтер — Директор ФЭД
- **Ознакомлены**: Руководитель проекта, Руководитель Грантополучателя (М.П.)

Для **итогового** заключения: дополнительно утверждается Решением Правления АО «Фонд науки».

## Этап 6: Принятие решения

По результатам АЦИВС менеджер рекомендует одно из решений:

| Решение | Когда |
|---|---|
| **Принять** | Все документы в порядке, нарушений нет |
| **Вернуть на доработку** | Есть замечания, устранимые в срок (10 рабочих дней) |
| **Инициировать выездной АЦИВС** | Серьёзные сомнения в достоверности документов |
| **Инициировать расторжение** | Грубые нарушения, нецелевое использование |

## Ежемесячный мониторинг

Помимо проверки отчётов по этапам, менеджер ежемесячно собирает:
- Табели учёта рабочего времени
- Расчётно-платёжные ведомости
- Платёжные поручения по ФОТ

## Регистрация в АО «НЦ ГНТЭ»

Через https://is.ncste.kz/:
1. Зарегистрировать грантополучателя (при создании стартап-компании)
2. Зарегистрировать проект и отчёт
3. Проверить регистрацию всех членов проектной группы (при заменах — зарегистрировать новых)
