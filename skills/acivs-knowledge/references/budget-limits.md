## ШАГ 0 — какую КД применять (обязательно)

Каждый проект подчиняется КД **своего** цикла — того года, в котором объявлен
конкурс и заключён Договор гранта, а не года текущей проверки. Лимиты циклов
различаются (ФОТ 30% / 30% / 20%, распределение по годам 30/50/20 → 21/57/22,
справка БВУ 30% → 50%), поэтому **не подставляйте цифры «по умолчанию»**.

1. Определи цикл по данным проекта: название конкурса / срок реализации
   (2024-2026, 2025-2027, 2026-2028), дата и реквизиты Договора гранта.
2. Нет данных — спроси пользователя («проект какого цикла КД?»), не угадывай.
3. Бери значения из колонки нужного цикла и ссылайся на пункты **этого** цикла.

## Примечания и открытые вопросы

- **КД 2026-2028 — две редакции.** Скиллы опираются на редакцию в PDF (макс. грант 250 млн,
  82,5 / 85 / 82,5 млн по годам; нумерация п.10, 32, 40-41, 43, 80, 81, 83, 90, 91, 97, 103).
  Более ранний Word-вариант «final 09.10.2025» отличается (200 млн, пункты сдвинуты) —
  не использовать, если не подтверждено, что он действует.
- **⚠ Доход для Механизма 1.** Скиллы ранее требовали ≥10%; ни в одной из трёх КД
  этого порога нет (везде ≥15% от суммы гранта). Применять 15%, пока не
  подтверждён иной источник.
- **Механизм 1 / 2 / 3** — классификация циклов 2024-2026 и 2025-2027;
  в 2026-2028 вместо неё — тип грантополучателя.
- Прочие софинансируемые затраты (ст.12) — только из софинансирования во всех циклах.
