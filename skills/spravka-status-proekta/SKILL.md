# Справка о текущем статусе грантового проекта (АО «Фонд науки»)

## Назначение

Краткая (обычно 1 страница) текстовая справка о гранте на коммерциализацию РННТД — для внутреннего использования менеджером ДКТ (брифинг руководству, приложение к письму в Комитет науки, материал к заседанию Правления/ННС). Формат — связный текст, НЕ таблица (для табличного «паспорта проекта» используется отдельный скилл karta-vnedreniya).

## Триггер

Пользователь просит «справку по проекту», «справку о статусе», часто прикладывая пример готовой справки по другому проекту как образец формата — в этом случае строго повторяй структуру, форматирование и стиль формулировок из образца, меняя только содержание.

## Источники данных (собрать перед написанием)

Прочитай все доступные документы по проекту и сверь цифры между ними, отдавая приоритет более свежим/официальным источникам:

1. **Договор о предоставлении гранта** — стороны (Победитель конкурса / Заявитель, Грантополучатель, Частный-партнер — иногда это одно и то же лицо, иногда три разных юрлица), общая сумма гранта по этапам, срок реализации проекта, место (юридический адрес Грантополучателя).
2. **Дополнительные соглашения (ДС)** к договору — если есть, ИМЕННО ОНИ дают актуальную Смету расходов (Приложение №2) с суммами гранта/софинансирования по этапам. Смета в исходном Договоре или в черновике («проект договора») может быть устаревшей — при расхождении цифр между черновиком и более поздним ДС верь ДС (более новая дата = более высокий приоритет).
3. **Заключение АЦИВС** (промежуточное/итоговое, по последнему рассмотренному этапу) — дата заключения, факт по гранту/софинансированию за этап, выполнение мероприятий Календарного плана, выявленные нарушения (или их отсутствие), суммы экономии/возврата, аффилированность поставщиков и т.д.
4. **Письмо в Комитет науки (КН)** по данному отчёту — подтверждает, на каком этапе рассмотрения находится отчёт (направлен на ННС / рассмотрен / решение принято), реквизиты решений ННС/Правления.
5. **Конкурсная заявка / Тех. план** — цель проекта и конкурентные преимущества продукта (если нужно развёрнуто описать цель проекта).
6. **Карта внедрения** (если уже создана по проекту) — плановые KPI (рабочие места, объём реализации, налоги), но НЕ используй как источник для сумм гранта/софинансирования, если есть более авторитетный источник (Смета из ДС).

Если цифры из разных документов противоречат друг другу — не выбирай наугад: разберись, какой документ актуальнее (более поздняя дата/номер ДС), и при сохранении справки как файла коротко упомяни в чате, какой источник использован, если расхождение существенное.

## Структура и форматирование (строго по образцу)

Документ .docx, шрифт Times New Roman, 14 pt, выравнивание по ширине (justify) для всех абзацев кроме заголовка (по центру). Создавать через python-docx (не редактировать существующий файл — этот формат создаётся с нуля под каждый проект).

Порядок абзацев:

1. Пустая строка (по центру)
2. **«СПРАВКА»** — по центру, жирный
3. Пустая строка (по центру)
4. **«ТОО «Название» DPXXXXXXXX - »** (жирным, включая тире) + *«Название проекта»* (курсивом, в кавычках, с точкой в конце) — один абзац
5. «Заявитель: ТОО «...»,» — если Заявитель (Победитель конкурса) и Грантополучатель разные юрлица, указать полное название и БИН заявителя. Если это одно и то же лицо — можно объединить строки 5 и 6 или явно отметить совпадение.
6. «Грантополучатель: ТОО «...»,» — при необходимости добавить «(выступает также Частным-партнером)», если роли совмещены.
7. «Грант - [общая сумма по договору] тенге, факт – [фактически перечислено на отчётную дату, обычно = сумма за завершённые этапы] тенге [(перечислено за N-й этап), если уместно].»
8. «Период реализации: ГГГГ-ГГГГ годы.» (годы начала и окончания проекта по договору)
9. «Место реализации: [юридический / фактический адрес производства].»
10. «Цель проекта: » (жирным только само «Цель проекта:») + краткая формулировка цели проекта одним-двумя предложениями (обычным начертанием).
11. Абзац о последнем АЦИВС: «По итогам реализации N-го этапа в [месяц] [год] года составлен АЦИВС, согласно которому мероприятия Календарного плана исполнены [в полном объёме / не в полном объёме — с указанием деталей].»
12. Абзац о суммах этапа: «Сумма финансирования составила - [сумма гранта за этап] тенге, а софинансирования - [сумма софинансирования за этап] тенге [(исполнено на 100%) / с указанием % исполнения].»
13. **Если есть нарушения/риски** (аффилированность, неполное исполнение софинансирования, замечания аудита и т.п.) — отдельный абзац с подробным описанием: в чём нарушение, по какому договору/сумме, как оно было устранено (доп. документы, возврат средств) и итоговый % исполнения после устранения. Если нарушений нет — этот абзац заменяется короткой фразой в абзаце 12 или отдельным коротким абзацем: «Нарушений целевого использования средств не выявлено; образовавшаяся экономия в размере [сумма] тенге возвращена в Фонд.» (если была экономия).
14. **Опционально**, если есть значимое дополнительное достижение (патент, офтейк-контракт и т.п.): «Также Грантополучателем [получен патент №... / заключены соглашения с ...].»
15. **«Статус:»** (жирным только слово) + текущий статус рассмотрения: «направлен на рассмотрение ННС/Правления по вопросу [...]» или, если решение уже принято, второй абзац: «Решением ННС протокол №... выписка №... от ... вопрос [снят с рассмотрения / одобрено дальнейшее финансирование / иное].» Ключевую суть решения (например «о приостановлении финансирования») можно выделить жирным внутри абзаца, как в образце.
16. Пустая строка в конце.

## Проверка перед выдачей

- Убедиться, что суммы гранта/софинансирования за этап из абзаца 12 совпадают с данными заключения АЦИВС (не с плановыми цифрами из черновика Приложения 4).
- Убедиться, что «факт» в строке «Грант -» логически согласован с описанным этапом (обычно это сумма, реально перечисленная на отчётную дату, а не весь плановый грант).
- Отрендерить документ в PDF/JPEG (soffice.py --convert-to pdf + pdftoppm) и визуально сверить с образцом — при наличии образца в диалоге ориентироваться на его форматирование поэлементно (жирность, курсив, порядок полей).
- Сохранить итоговый .docx в папку проекта пользователя с понятным именем, например «Справка_DPXXXXXXXX.docx» или «Справка по ТОО «Название» DPXXXXXXXX.docx» (по аналогии с загруженными пользователем образцами).

## Отличия от табличного формата

Ранее для справок использовался также табличный формат (11 строк: Заявитель / Грантополучатель / Частный партнер / Грант / Софинансирование / Период реализации / Цель проекта, преимущества / Достигнутые результаты / Рабочие места / Продажи / Налоги). Если пользователь явно просит «в таком формате» и прикладывает образец текстовой справки (как в этом скилле) — используй текстовый формат. Если прикладывает образец с пустой таблицей — используй табличный формат, заполняя пустые ячейки по той же логике сбора данных (см. раздел «Источники данных» выше), с пометкой план/факт для полей рабочие места/продажи/налоги, если проект ещё не достиг этапа получения дохода.
