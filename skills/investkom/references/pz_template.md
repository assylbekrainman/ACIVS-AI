# Шаблон Пояснительной записки для Инвестиционного комитета

## Назначение

Пояснительная записка (ПЗ) готовится менеджером ДКТ АО «Фонд науки» и выносится на рассмотрение Инвестиционного комитета при необходимости:
- включения нового участника на вакантную должность в проектной группе
- замены участника проектной группы

---

## Структура документа

### 1. Заголовочный блок (по центру, Times New Roman 12pt, жирный / обычный)

```
ПОЯСНИТЕЛЬНАЯ ЗАПИСКА
по вопросу повестки дня заседания
Инвестиционного комитета АО «Фонд науки»

«О [включении участника в проектную группу / замене участника]
по проекту [ИРН] «[Название проекта]»»
```

> Тема в кавычках — с отступом слева (~1 см), без центрирования.

---

### 2. Вводный абзац (отступ первой строки 1.25 см, выравнивание по ширине)

**При включении на вакансию:**
```
[Наименование ГП] (далее – Грантополучатель) реализует проект [ИРН] «[Название]»
(далее – Проект), согласно Договору о предоставлении гранта на коммерциализацию
результатов научной и (или) научно-технической деятельности №[номер] от [дата] г.
(далее – Договор).
```

**При замене:**
```
[Наименование ГП] (далее – Грантополучатель) реализует проект [ИРН] «[Название]»
(далее – Проект), согласно Договору о предоставлении гранта на коммерциализацию
результатов научной и (или) научно-технической деятельности №[номер] от [дата] г.
(далее – Договор).
```

---

### 3. Абзац об обращении ГП

**При включении:**
```
Грантополучатель обратился письмом в АО «Фонд науки» исх. №[номер] от [дата] г.
касательно включения в состав проектной группы [ФИО кандидата полностью]
на вакантную должность [должность] (жирный + подчёркнутый) с занятостью
на полную ([X],0) ставку.
```

**При замене:**
```
Грантополучатель обратился письмом в АО «Фонд науки» исх. №[номер] от [дата] г.
касательно замены [должность] [ФИО заменяемого] на [ФИО нового кандидата]
(занятость в проекте — [полная/неполная] ставка).
```

---

### 4. Функциональные обязанности

```
Функциональные обязанности [должность] в Проекте следующие:
```

Затем список через тире (не маркеры), каждый пункт с маленькой буквы, в конце точка с запятой, последний — точка:

```
- [обязанность 1];
- [обязанность 2];
- [обязанность N].
```

---

### 5. Сведения о кандидате

```
Сведения о кандидате:

[ФИО полностью], дата рождения: [ДД.ММ.ГГГГ] г.

Образование:
- [год] г. — [степень], [Университет], специальность «[название]»;
- [год] г. — [степень], [Университет], специальность «[название]».

Опыт работы: [X] лет в сфере [описание]. В том числе:
- [период]: [Организация] — [должность];
- [период]: [Организация] — [должность].
```

---

### 6. Финансовый блок

**При включении на существующую вакансию:**
```
Включение [ФИО кратко] в состав проектной группы на вакантную должность
[должность] не несёт никаких дополнительных финансовых затрат. Внесение изменений
в Договор не требуется, поскольку должность [должность] предусмотрена действующим
штатным расписанием по Проекту (ставка — [X],0; оклад — [сумма] тенге).
```

**При замене:**
```
Замена членов команды по Договору не несёт никаких финансовых затрат. Внесение
изменений в Договор не требуется.
```

---

### 7. Резолютивный абзац

**При включении:**
```
Учитывая вышеизложенное, вопрос «О включении [ФИО полностью] в состав проектной
группы и штатное расписание по Договору о предоставлении гранта на коммерциализацию
результатов научной и (или) научно-технической деятельности №[номер] от [дата] г.»
выносится на рассмотрение Инвестиционного комитета.
```

**При замене:**
```
Учитывая вышеизложенное, вопрос «О замене [должность] и изменении штатного расписания
по Договору о предоставлении гранта на коммерциализацию результатов научной и (или)
научно-технической деятельности №[номер] от [дата] г.» выносится на рассмотрение
Инвестиционного комитета.
```

---

### 8. Приложение (курсив)

```
Приложение:
1. Копия письма исх. №[номер] от [дата] г. и пакет сопутствующих документов.
```

---

### 9. Подпись

```
Директор ДКТ                                     С. Мажикенов
```

Имя — по правому краю (через tab stop), должность — по левому краю.

---

## Параметры форматирования

| Параметр | Значение |
|---|---|
| Шрифт | Times New Roman |
| Размер | 12 pt (24 half-point) |
| Межстрочный интервал | Полуторный (276 twips) |
| Выравнивание | По ширине (Justify) |
| Отступ первой строки | 1.25 см (709 twips) |
| Поля страницы | Верх: 2.5 см, Низ: 2.0 см, Лево: 3.0 см, Право: 1.5 см |
| Формат | A4 (11906 × 16838 DXA) |
| Заголовок | Жирный, по центру, без отступа |
| Тема ПЗ | Обычный, с отступом слева ~651 twips |
| Список обязанностей | Тире (-), LevelFormat.BULLET, отступ left: 720, hanging: 360 |

---

## Частые ошибки при подготовке ПЗ

1. Написание «ТОО» вместо правильной организационно-правовой формы ГП — всегда уточняй
2. Неполное ФИО кандидата (нужны имя, отчество, фамилия полностью в тексте)
3. Неправильная дата Договора — сверяй с первым листом Договора, не с письмом ГП
4. Отсутствие слова «вакантную» при включении на незанятую ставку
5. Указание изменения Договора, когда оно не требуется (если должность уже в штатном)
6. Форматирование списка через маркеры вместо тире
