# Проверка комплектности документов для заключения Договора гранта

Этап 3 процесса заключения Договора (см. dogovor-navigator). Источник: «Перечень необходимых документов для комплексной проверки статуса грантополучателя и заключения договора с ним».

## Как работать

1. Определи, чей пакет проверяется: Грантополучатель (юрлицо), Заявитель-Победитель (юрлицо) или Заявитель-Победитель (физлицо). Могут проверяться одновременно два пакета (ГП + Заявитель).
2. Пройди по соответствующему чек-листу. Для каждой позиции определи: предоставлен / не предоставлен / предоставлен с дефектом (нет заверения, истёк срок, не читается, не тот орган).
3. Особое внимание — требованиям заверения: «заверено печатью ГП; при отсутствии печати — нотариальное заверение».
4. Сформируй акт комплектности (формат в конце) и перечень того, что запросить у ГП.

## Чек-лист А. Документы Грантополучателя (юрлицо)

| № | Документ | Требования |
|---|----------|------------|
| 1 | Справка о государственной регистрации/перерегистрации юридического лица | актуальная (eGov/КГД) |
| 2 | Копия устава | заверена печатью ГП; без печати — нотариально. Если деятельность по типовому уставу — письменное подтверждение |
| 3 | Копия удостоверения личности первого руководителя | действующее |
| 4 | Решение/Протокол органа управления (или выписка) об избрании/назначении первого руководителя | заверено печатью; без печати — нотариально |
| 5 | Справка банка об открытии/наличии текущего счёта для средств софинансирования | на фирменном бланке банка, с печатью (при наличии счёта) |
| 6 | Доверенность уполномоченному лицу на право подписания договора (при необходимости) | + копия удостоверения личности доверенного лица + копия приказа о назначении на должность |
| 7 | Копия лицензионного договора о передаче прав на ОИС, зарегистрированного в НИИС (при наличии патента), ИЛИ копия договора по передаче прав на РННТД | заверена печатью ГП; оригинал — для сверки. В особых случаях с обоснованием допускается завершение процедуры в течение не более 3 месяцев реализации проекта. Детальная проверка — скилл dogovor-ois-check |
| 8 | Корпоративное решение органа управления о заключении договора о предоставлении гранта | заверено печатью (без печати — нотариально); ОБЯЗАТЕЛЬНО указаны: сумма договора, наименование проекта, ИРН. Орган — согласно законодательству РК и учредительным документам (единственный акционер, общее собрание, совет директоров и т.п.) |
| 9 | Свидетельство о постановке на регистрационный учёт по НДС | действующее (либо подтверждение подпадания под ст.373/374 НК РК) |
| 10 | Документы по финансовой устойчивости | 1) выписка по расчётам с бюджетом (уплаченные налоги) за последние 3 года — kgd.gov.kz, кабинет налогоплательщика; 2) справка о финансовой устойчивости — goszakup.gov.kz, профиль участника, раздел «Финансовая устойчивость». Норматив (п.23 КД): деятельность ≥1 года, налоговые отчисления ≥5 млн тг в среднем ежегодно, либо при спецрежиме — финотчётность с годовым оборотом ≥10 млн тг. Не применяется к стартап-компаниям |

### Дополнительные проверки статуса ГП (раздел 4 КД)

- [ ] ГП не банкрот, нет заявленных требований о признании банкротом, не в стадии ликвидации/санации, не включён в реестр недобросовестных поставщиков (п.21 КД) — проверить по открытым реестрам.
- [ ] В уставе предусмотрены виды деятельности, необходимые для проекта; есть требуемые лицензии/разрешения — либо обязательство обеспечить их до заключения Договора (п.22 КД).
- [ ] Первый руководитель ГП имеет ≥2 лет руководящего стажа (п.49 КД).

### Дополнительно для стартап-компании (п.24-25, 30 КД)

- [ ] Стартап зарегистрирован после объявления результатов Конкурса и до подписания Договора.
- [ ] Заявитель (или его представители) входит в состав учредителей/участников на весь срок реализации проекта.
- [ ] Договор гаранта возврата средств гранта с каждым учредителем (пропорционально доле в уставном капитале, Прил.5 КД).
- [ ] Соглашение о присоединении стартап-компании к Договору о совместной деятельности.

## Чек-лист Б. Документы Заявителя-Победителя (юрлицо)

| № | Документ | Требования |
|---|----------|------------|
| 1 | Справка (или копия свидетельства) о госрегистрации/перерегистрации юрлица | — |
| 2 | Копия устава или положения о филиале/представительстве | заверена печатью (без печати — нотариально); типовой устав — письменное подтверждение; для филиала — копия генеральной доверенности руководителю филиала (при наличии) |
| 3 | Копия удостоверения личности первого руководителя или уполномоченного лица с правом подписания договора | — |
| 4 | Решение/Протокол (или выписка) об избрании/назначении первого руководителя | заверено печатью (без печати — нотариально) |
| 5 | Доверенность уполномоченному лицу (при необходимости) | + копия удостоверения доверенного лица + копия приказа о назначении |
| 6 | Выписка из решения участников/единственного участника об участии в уставном капитале стартап-компании | для механизма со стартап-компанией |
| 7 | Корпоративное решение о заключении договора гранта | заверено печатью (без печати — нотариально); с суммой договора, наименованием проекта, ИРН |

## Чек-лист В. Информация и документы Заявителя-Победителя (физлицо)

1. копия удостоверения личности (реквизиты, контактная информация);
2. адрес постоянной и временной (при наличии) регистрации;
3. адрес постоянного проживания;
4. номер телефона, зарегистрированного за Заявителем;
5. адрес электронной почты;
6. банковские реквизиты.

## Типовые дефекты (проверять всегда)

- Копия не заверена печатью и нет нотариального заверения.
- В корпоративном решении отсутствует сумма договора, наименование проекта или ИРН, либо решение принято некомпетентным органом.
- Справки устарели (регистрация, банк — актуальность на дату проверки).
- Удостоверение личности просрочено; ФИО руководителя в документах расходится с решением о назначении.
- Доверенность не покрывает право подписания договора о предоставлении гранта.
- БИН/наименование в документах не совпадают между собой и с заявкой (12-значный БИН).
- Нет НДС-регистрации и нет подтверждения по ст.373/374 НК РК — блокер (обязанность быть плательщиком НДС с даты подписания Договора).

```
| № | Документ | Статус | Замечание |
|---|----------|--------|-----------|
| 1 | ... | ✅/⚠️/❌ | ... |

Итог: комплектен / не комплектен.
Запросить у ГП: 1) ... 2) ...
```
