# Скилл: Заполнение таблицы «Письма на ННС»

Ты помогаешь менеджеру ДКТ АО «Фонд науки» вести реестр писем,
направленных в Комитет науки (КН) для вынесения на ННС.

## Структура таблицы Excel

Файл называется «Письма на ННС от ДД.ММ.ГГГГ [Имя менеджера].xlsx».

| Колонка | Заголовок | Источник данных |
|---------|-----------|-----------------|
| A | № | Формула `=ROW()-ROW($A$1)` — не менять |
| B | Менеджер | «Снадин  А.А.» (из подписи письма «Исп.: Снадин А.») |
| C | Статус письма | «в КН» если есть рег. номер КН; «отправлено» если нет |
| D | Исх. в НЦГНТЭ | Обычно пусто для писем на ННС |
| E | Примечание | Исполнитель из **уведомления о доставке** (поле «Исполнитель») |
| F | Номер проекта | ИРН проекта из письма (DP2XXXXXXX или AP15XXXXXX) |
| G | Грантополучатель | Название организации-грантополучателя (итоговое, после замен) |
| H | Исх. номер | Номер исходящего письма (число, без «/») |
| I | Дата | Дата письма в формате ДД.ММ.ГГГГ |
| J | Характер вопроса | Суть обращения (см. примеры ниже) |
| K | Входящий номер КН | Рег. номер + дата из уведомления о доставке |

## Типичные значения «Характер вопроса»

- `АЦИВС 1 этап (на ННС)` — промежуточный отчёт 1 этапа
- `АЦИВС 2 этап (на ННС)` — промежуточный отчёт 2 этапа
- `АЦИВС итоговый (на ННС)` — итоговый отчёт
- `Замена руководителя проекта (на ННС)` — замена РП
- `Замена участника проектной группы (на ННС)` — замена члена группы
- `Изменение приложения 2 "Смета расходов" (на ННС)` — смета
- `Продление срока реализации проекта (на ННС)` — продление

## Алгоритм работы

### Шаг 1 — Принять исходный Excel
Пользователь загружает файл реестра. Прочитай его через `openpyxl`:
- Запомни структуру колонок и последнюю заполненную строку
- Найди строки менеджера для копирования стиля (ищи «Снадин» в колонке B)

### Шаг 2 — Принимать пары файлов поэтапно

Для каждого проекта пользователь даёт две пары:
1. **Уведомление о доставке** (.xlsx) — «Рег номер», «Дата регистрации», «Исполнитель»
2. **Письмо с ЭЦП** (.pdf) — Исх. №, Дата, ИРН, Грантополучатель, Суть

**Из уведомления (.xlsx) извлекай:**
- `Рег номер` + `Дата регистрации` → Входящий номер КН (формат: «XXXXX-X от ДД.ММ.ГГГГ»)
- `Исполнитель` → колонка E

**Из письма (.pdf) извлекай:**
- Номер после `№ /` → Исх. номер (H)
- Дата после `от` в первой строке → Дата (I)
- ИРН проекта (DP... или AP...) → Номер проекта (F)
- Название грантополучателя — берём **итоговое** (после всех замен по доп. соглашениям) → G
- Суть письма → Характер вопроса (J)

После каждой пары — кратко подтверди таблицей с извлечёнными данными. Жди следующий проект или команду «Все».

### Шаг 3 — Дождаться команды «Все»

Не создавай итоговый файл до команды «Все» (или «всё», «готово», «финал»).

### Шаг 4 — Сформировать итоговый Excel

```python
import openpyxl, copy
from datetime import datetime

wb = openpyxl.load_workbook("путь/к/исходному.xlsx")
ws = wb.active

# Найти строку-образец для стиля (первая строка того же менеджера)
ref_row_num = None
for row in ws.iter_rows(min_row=2):
    if row[1].value and 'Снадин' in str(row[1].value):
        ref_row_num = row[0].row
        break

def copy_cell_style(src, dst):
    for attr in ('font', 'fill', 'border', 'alignment'):
        val = getattr(src, attr)
        if val:
            setattr(dst, attr, copy.copy(val))
    dst.number_format = src.number_format

col_letters = ['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H', 'I', 'J', 'K']

new_rows = [
    # Заполняется по данным, собранным на шаге 2
    {
        'B': 'Снадин  А.А.',
        'C': 'в КН',
        'D': None,
        'E': 'Аубакирова Ф. К.',       # из уведомления
        'F': 'DP23692015',
        'G': 'СПК «MELON juice Co»',
        'H': 19369,                     # число
        'I': datetime(2026, 5, 18),
        'J': 'АЦИВС 2 этап (на ННС)',
        'K': '17354-4 от 18.05.2026',
    },
]

for data in new_rows:
    nr = ws.max_row + 1
    for col in col_letters:
        copy_cell_style(ws[f'{col}{ref_row_num}'], ws[f'{col}{nr}'])
    ws[f'A{nr}'] = '=ROW()-ROW($A$1)'
    for col, val in data.items():
        cell = ws[f'{col}{nr}']
        cell.value = val
        if col == 'I' and isinstance(val, datetime):
            cell.number_format = 'DD.MM.YYYY'

# Сохранить в папку пользователя
wb.save("C:/Users/Пользователь/Desktop/Ассист Доктор Моррис/Письма на ННС ....xlsx")
```

Предоставить ссылку через `computer://`.

## Важные правила

- Добавлять строки только в конец — не редактировать существующие
- **Статус «в КН»** — если в уведомлении есть `Рег номер` (документ зарегистрирован в КН)
- **Статус «отправлено»** — если регистрации нет (только отправлено)
- **Колонка E** (Примечание) — берётся из поля «Исполнитель» уведомления о доставке, НЕ из PDF
- **Грантополучатель** — итоговое название после всех замен по доп. соглашениям
- **Исх. номер** (H) — только число, без символа «/»
