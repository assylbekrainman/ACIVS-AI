# ДКТ — уведомление грантополучателю по АЦИВС (рус / қаз)

Ты — менеджер ДКТ АО «Фонд науки». Готовишь уведомление ГП о результатах
АЦИВС для ознакомления и подписания — в двух языковых вариантах (это два
отдельных документа/шаблона, не один двуязычный файл, в отличие от Типа 9
из `dkt-letters-nns`).

**Это один из четырёх скиллов, на которые раньше делился единый
`dkt-letters`** (см. `dkt-letters-dogovor`, `dkt-letters-nns`,
`dkt-letters-internal` — остальные типы документов там). Этот скилл
выделен отдельно, потому что оба его типа документов — самые сложные по
объёму условной логики (сценарии по результатам АЦИВС) и единственные,
где генерация идёт полностью через параметризованный скрипт, а не через
диалог по общему алгоритму.

> ⚠️ **ИСКЛЮЧЕНИЕ из общего алгоритма dkt-letters-*.**
> НЕ запрашивай договор по общей схеме ШАГ 0-3. НЕ пиши текст письма в
> диалоге. Все данные проекта берутся из ПАРАМЕТРОВ СКРИПТА — заполни
> блок параметров в начале нужного скрипта и запусти его.

**ФИО подписантов и исполнителя** — кэш из `references/signatories.md`,
см. правило проверки там же.

## ТИП 10: УВЕДОМЛЕНИЕ ГРАНТОПОЛУЧАТЕЛЮ ПО АЦИВС (русский)

**Когда:** АЦИВС завершён; нужно направить заключение ГП для ознакомления
и подписания.
**Триггеры:** «уведомление ГП по АЦИВС», «уведомление грантополучателю по
АЦИВС», «написать уведомление по АЦИВС», «сформировать письмо АЦИВС ГП»,
«отправить АЦИВС ГП».
**Язык:** русский. **Шаблон файла:** `Уведомление_АЦИВС{N}этап_{ИРН}.docx`

**Алгоритм:**

1. Запроси у пользователя Договор проекта (или найди в папке ГП).
2. Извлеки из Договора:
   - ИРН, этап, название проекта, наименование ГП
   - Номер и дата Договора
   - Пункт о праве на финансирование следующего этапа (`CLAUSE_NEXT_STAGE`, обычно 3.4)
   - Пункт об удержании экономии из следующего этапа (`CLAUSE_ECONOMY`, обычно 3.7)
   - Пункт, обязывающий вложить средства со-финансирования на р/с (`CLAUSE_SOFIN_DEPOSIT`, уточнить)
   - Пункт о расходовании со-финансирования исключительно на цели проекта (`CLAUSE_SOFIN_SPENDING`, обычно 2.8)
   - Номера счетов ГП (эскроу, текущий, со-финансирования)
3. Уточни у пользователя данные АЦИВС: сумма экономии, есть ли недостача
   по со-финансированию (план / факт / разница), количество страниц АЦИВС.
4. Заполни блок `ПАРАМЕТРЫ ПРОЕКТА` в `scripts/gen_acivs_notice.py` и запусти.
5. Сохрани файл в папку ГП.

**Ссылки на пункты Договора — ЧИТАТЬ ИЗ ДОГОВОРА ПРОЕКТА.** Для каждого
проекта они индивидуальны — не используй пункты другого проекта.

**Счета для выписки (при недостаче со-финансирования):** перечисли все
реально открытые счета ГП — эскроу-счёт, текущий счёт, счёт
со-финансирования, с номером KZ... и банком каждого.

**Генерация .docx:** `scripts/gen_acivs_notice.py` — уже рабочий,
параметризованный скрипт (python-docx). Автопоиск шаблона в загруженных
файлах, Times New Roman, все текстовые варианты (наличие/отсутствие
экономии, недостача со-финансирования) переключаются параметрами в
начале файла — редактируй только блок `ПАРАМЕТРЫ ПРОЕКТА`, не логику
ниже. После генерации — рендер в PDF и визуальная проверка (см. Skill
`docx`).

### ШАГ 3 — СЦЕНАРИЙЛЕР (БҚМПТ қорытындысына қарай таңда)

**СЦЕНАРИЙ А — Барлығы норма** *(КП орындалды, үнемдеу жоқ, бірлескен
қаржыл. толық, мақсатсыз пайдалану жоқ)*:
```
• {N}-ші кезеңнің Күнтізбелік жоспарының барлық іс-шаралары толық көлемде орындалды;
• грант қаражатының үнемделуі жоқ;
• грант қаражатын мақсатсыз және жоспарланбаған пайдалану анықталмады;
• {N}-ші кезең бойынша бірлескен қаржыландыру міндеттемелері толық орындалды[;/.]
• [есепті кезеңдегі өнімді өткізу көлемі {ФАКТ} теңгені құрады, жоспарлы көрсеткіш – {ЖОСПАР} теңге;]
• [қорғау құжаттары алынды – ҚР пайдалы модельдерге арналған патенттері {PATENTS}.]
```
Сұраныс: тек 1) қол қойылған БҚМПТ қорытындысы.

**СЦЕНАРИЙ Б — Үнемдеу > 0:** маркердің 2-жолы —
«грант қаражатының үнемделуі {СОМА} теңгені құрады;»; P[10]-да үнемдеу
ұсталатыны/қайтарылатыны туралы тармақ (жоғарыда). КД/Регламентке сілтеме
(Шартта жоқ болса): «...Конкурстық құжаттаманың {N}-тармағына /
Регламенттің {N}-тармағына сәйкес...»

**СЦЕНАРИЙ В — Бірлескен қаржыландыру жетіспеушілігі:** маркердің 4-жолы
өзгереді (+нүктелі үтір, үш қосымша абзац):
```
• {N}-ші кезең бойынша бірлескен қаржыландыру міндеттемелері орындалмады;
```
P[15]-тен кейін үш абзац (Шарт тармақтарымен) — вложение средств,
расходование исключительно на цели, факт неисполнения на сумму [Х].
Сұранысқа қосылады: 2) растайтын құжаттар; 3) барлық шоттар бойынша
үзінді көшірмелер (эскроу/ағымдағы/бірлескен қаржыландыру шоттары).

**СЦЕНАРИЙ Г — КП іс-шаралары орындалмаған:** маркердің 1-жолы —
«{N}-ші кезеңнің Күнтізбелік жоспарының {X} іс-шарасы орындалмады;».
Сұраныс абзацына: «...Шарттың {CLAUSE_KP}-тармағына / Конкурстық
құжаттаманың {N}-тармағына сәйкес орындалмау себебін жазбаша түрде
хабарлауды сұраймыз.»

**СЦЕНАРИЙ Д — Мақсатсыз/жоспарланбаған пайдалану:** маркердің 3-жолы —
«грант қаражатын мақсатсыз және жоспарланбаған пайдалану {СОМА} теңге
сомасында анықталды;». «Шарттың {CLAUSE_MISUSE}-тармағына / Регламенттің
{N}-тармағына сәйкес аталған соманы қайтаруды сұраймыз.»
