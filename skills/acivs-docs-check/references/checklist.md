# Полный чек-лист подтверждающих документов по статьям СР

Источник: «Перечень подтверждающих документов по статьям Сметы расходов» АО «Фонд науки»

## Статья 1. ФОТ

### Обязательные документы:
1. Копия утверждённого штатного расписания (per stage)
2. Копии индивидуальных трудовых договоров (per stage)
3. Табели учёта рабочего времени (monthly)
4. Приказ о выходе в выходные + письменное согласие (if applicable)
5. Письмо согласования замены члена группы (if applicable)
6. Расчётные ведомости з/п: ИПН, ОПВ, СО, СН, ОСМС (monthly)
7. Платёжные поручения: з/п, ИПН, ОПВ — с отметкой банка (monthly)

### Проверки:
- Суммы РПВ соответствуют штатному расписанию
- Состав группы 4-6 человек, соответствует Договору
- РП на полный рабочий день (проверить табель)
- Трудовые договоры покрывают период этапа
- ИПН и ОПВ из гранта; СН, СО, ОСМС — НЕ из гранта
- Итого ФОТ ≤ 30% от суммы гранта

### Красные флаги:
- РП на 0.5 ставки
- Отсутствие трудового договора
- Оплата СН/СО/ОСМС из гранта
- ФОТ > 30%
- Замена без согласования Фонда

## Статья 2. Закуп оборудования и ПО

### Обязательные документы:
1. Договоры поставки (эскроу в реквизитах, ИРН в преамбуле) (per purchase)
2. Счета-фактуры ЭСФ (per purchase)
3. Накладные + доверенности (дата доверенности ≤ дата накладной) (per purchase)
4. Акты приёма-передачи (if applicable)
5. Акты ввода в эксплуатацию (if applicable)
6. Платёжные поручения с отметкой банка (per purchase)
7. Фото оборудования с логотипом АО «Фонд науки» (per equipment)
8. Паспорт оборудования / сертификат ПО (per equipment)
9. Документ гарантийного обслуживания / договор ИТС (per equipment)

### Проверки:
- Оборудование НОВОЕ (не б/у)
- Поставщик ≠ сторона Договора (п.41 КД)
- Реквизиты эскроу в договоре поставки
- Номер проекта в преамбуле договора
- Доверенность датирована не позднее накладной
- Логотип Фонда на фото
