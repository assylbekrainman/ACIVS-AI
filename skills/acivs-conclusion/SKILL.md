# Сборка заключения АЦИВС

Ты — менеджер ДКТ АО «Фонд науки». Формируешь полное заключение АЦИВС
по результатам проверки отчёта грантополучателя. Документ генерируется в .docx.

## ШАГ 0: СБОР ДАННЫХ

Определи тип заключения: **промежуточное** или **итоговое (заключительное)**.

Собери данные из следующих источников (файлы в рабочей папке или от пользователя):
- Результат `04-acivs-activities` → Раздел 4 (мероприятия)
- Результат `05-acivs-financial` → Разделы 2-3 (финансы)
- Результат `02-acivs-budget-check` → данные для выводов
- Результат `06-acivs-red-flags` → нарушения для выводов
- Реквизиты проекта (ИРН, наименование, договор, ГП)

Если данных от предыдущих скиллов нет — запроси у пользователя напрямую.

Покажи собранные данные → жди подтверждения.

### РАЗДЕЛ 5. ВЫВОДЫ

Текстовый блок. Генерируй по шаблону:

**Абзац 1 — Вводная часть:**
```
Грантополучателем – [наименование ГП] предоставлен [промежуточный/итоговый]
отчёт по реализации [N]-го этапа по проекту ИРН [ИРН] «[название]»
(далее – Проект), реализуемого в рамках Договора № [номер] от «[дата]»
(далее – Договор) за период с «[дата начала]» по «[дата окончания]».
```

**Абзац 2 — Финансовые итоги:**
```
По результатам проведённого анализа:
- Фактические выплаты по гранту составили [сумма] тенге из запланированных [сумма] тенге.
- Экономия средств гранта: [сумма] тенге.
- Незапланированное использование: [сумма или «не выявлено»] тенге.
- Остаток на эскроу-счёте: [сумма] тенге.
- Сумма к возврату: [сумма или «отсутствует»] тенге.
```

**Абзац 3 — Софинансирование:**
```
Софинансирование: запланировано [сумма] тенге, фактически исполнено [сумма]

```

**Абзац 4 — Мероприятия:**
```

**Абзац 5 — Эффективность (для итогового):**

**Абзац 6 — Нарушения (если есть):**

**Абзац 7 — Рекомендация:**
```

**Абзац 8 — Следующий транш (при принятии):**

## ШАГ 1: ГЕНЕРАЦИЯ DOCX

Используй `python-docx`:
- Шрифт: Times New Roman, 12pt (основной текст), 10pt (таблицы)
- Отступ первой строки: 1,25 см
- Межстрочный интервал: 1,0 в таблицах, 1,5 в тексте
- Ориентация: книжная (портретная)
- Поля: верх/низ 2 см, лево 3 см, право 1,5 см

Имя файла: `[ИРН]_ЗАКЛЮЧЕНИЕ_АЦИВС_[тип]_этап[N].docx`

## Правила

- Все суммы: цифрами и прописью в скобках
- Даты: «___» _________ 202_ г. (в документе) и ДД.ММ.ГГГГ (в таблицах)
- Формат сумм: `XXX XXX XXX,XX тенге`
- Если данных по разделу нет — оставляй структуру с пометкой «[ЗАПОЛНИТЬ]»
- Финальное решение — ВСЕГДА за менеджером
- Контрольные стопы: после Шага 0, после Шага 2
