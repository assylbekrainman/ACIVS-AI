# API «Сведения по контрагентам (Открытые данные)» — портал КГД МФ РК

Источники:
- Инструкция «API сведения по контрагентам (Открытые данные)», выдана
  Администратором портала КГД МФ РК.
- https://portal.kgd.gov.kz/ru/pages/info-services/find-information-for-ip-ul

## Подключение

1. Получить токен `X-Portal-Token` у Администратора портала КГД МФ РК
   (отдельная процедура, не автоматизируется — официальный запрос от
   организации).
2. Все запросы идут на хост портала: `[portal-host]` в спецификации —
   подставляется `https://portal.kgd.gov.kz`, если Администратор КГД не
   выдал иной хост (например, отдельный контур для API).

## Эндпоинт

```
POST [portal-host]/services/isnaportal/public/get-sur-data
```

### Headers

| Заголовок | Значение |
|---|---|
| `X-Portal-Token` | токен, выданный Администратором КГД МФ РК |
| `Content-Type` | `application/json` |

### Тело запроса

```json
{
    "xin": "071140005693"
}
```

`xin` — ИИН (12 цифр, физлицо/ИП) или БИН (12 цифр, юрлицо).

### Расшифровка ключевых полей

| Поле | Смысл |
|---|---|
| `actuality` | дата актуальности данных |
| `name.ru` / `name.kk` | наименование (в примере пусто — зависит от типа субъекта) |
| `regDate` | дата регистрации |
| `residency` | резидент / нерезидент |
| `oked`, `okedName` | код и наименование ОКЭД (основной вид деятельности) |
| `vatInfo`, `vatDate` | статус и дата постановки на учёт по НДС |
| `taxMode`, `taxModeDate` | налоговый режим и дата его установления |
| `registrationInvalid` | регистрация признана недействительной |
| `reRegistrationInvalid` | перерегистрация признана недействительной |
| `operationsWOWork` | сделки, совершённые без фактического выполнения работ/услуг |
| `esfRestrinctions` | ограничения на выписку электронных счетов-фактур |
| `inactive` | налогоплательщик признан бездействующим |
| `regAddressAbsent` | отсутствие по месту регистрации |
| `bankrupt` | в реестре банкротов |
| `selfRegulatoryRegistry` | сведения из реестра субъектов саморегулирования |
| `courtDecisionRegistry` | наличие решения суда в реестре |
| `taxDebt`, `taxDebt1..4` | общая налоговая задолженность и её структура (тенге) |
| `statistics[]` | по годам: численность работников, уплаченные налоги, КНН/среднеотраслевой КНН, сумма НДС |

Значение `"Нет данных"` / `"Мәлімет жоқ"` в полях-реестрах означает
**отсутствие записи в этом конкретном реестре**, а не подтверждение
благонадёжности контрагента — при интерпретации это стоит явно оговаривать.

## Коды ошибок

| Код | Описание |
|---|---|
| 200 | Запрос выполнен успешно |
| 400 | Запрос содержит синтаксическую ошибку |
| 401 | Пользователь не авторизован |
| 404 | Доступ к сервису запрещён |
| 500 | Ошибка на сервере, запрос не выполнен |
