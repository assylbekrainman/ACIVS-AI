# АО «Народный Банк Казахстана» (Halyk) — раздел-заглушка, формат письма НЕ подтверждён

Этот файл существует, чтобы зафиксировать структуру («сюда добавится
`formatting-spec.md`, когда появится реальный пример»), а не потому что у
скилла уже есть рабочий формат письма для Halyk как банка эскроу-счёта.

## Что уже известно и надёжно (не требует нового примера)

Halyk уже присутствует в скилле в двух других ролях, не связанных с тем,
что сам Halyk — банк эскроу-счёта письма:

- Как банк-держатель транзитного/личного счёта сотрудника (получатель
  зарплаты): БИН **940140000385** (внимание — не путать с неверным
  `941240001151`, который встречался в одном из писем коллег, см.
  `references/bck/formatting-spec.md`), БИК HSBKKZKX, транзитный счёт
  KZ256010002200008667, КНП 332 — см. `references/shared/fund-payer-details.md`
  и `references/shared/transit-accounts.md`.
- Как банк, где у самого АО «Фонд науки» открыт расчётный счёт-плательщик
  (ИИК KZ026017111000000822 и другие варианты) — см.
  `references/shared/fund-payer-details.md`. Это тоже не то же самое, что
  Halyk в роли банка эскроу-счёта ГП.

## Чего не хватает

Реального письма или пустого бланка Halyk **в роли банка эскроу-счёта ГП**
(письмо, которое Фонд отправляет В Halyk с поручением перечислить деньги
с эскроу-счёта ГП) — нет ни одного. Без него нельзя описать формат письма
(язык, структуру, типографику, число подписантов, наличие контрольного
блока).

## Что делать при первом реальном запросе по Halyk

1. Скажи пользователю прямо: формат письма по Halyk не задокументирован,
   нужен реальный пример или пустой бланк банка.
2. Когда пример появится — заведи `references/halyk/formatting-spec.md` по
   образцу уже существующих разделов, извлекая типографику из XML
   документа, а не угадывая по картинке.
3. Реквизиты налогов/взносов и правило транзитных счетов уже общие для
   всех банков — переиспользуй их из `references/shared/`.
4. Обнови таблицу в `SKILL.md` (Шаг 0 и Шаг 3), убрав пометку «не
   подтверждён» для Halyk.
