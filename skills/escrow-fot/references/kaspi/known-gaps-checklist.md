# Kaspi Bank — раздел-заглушка, формат письма НЕ подтверждён

Этот файл существует, чтобы зафиксировать структуру («сюда добавится
`formatting-spec.md`, когда появится реальный пример»), а не потому что у
скилла уже есть рабочий формат письма для Kaspi Bank как банка
эскроу-счёта.

## Что уже известно и надёжно (не требует нового примера)

Kaspi Bank уже присутствует в скилле в другой роли — как банк-держатель
транзитного/личного счёта сотрудника (получатель зарплаты), а не как банк
эскроу-счёта самого письма. Эти данные подтверждены независимо и ими
можно пользоваться уже сейчас:

- БИН АО «Kaspi Bank»: 971240001315, БИК: CASPKZKA — см.
  `references/shared/fund-payer-details.md`.
- Транзитный счёт по зарплате: БИК CASPKZKA, ИИК KZ24722S000000686267,
  КНП 332 — см. `references/shared/transit-accounts.md`.

## Чего не хватает

Реального письма или пустого бланка Kaspi Bank **в роли банка
эскроу-счёта** (то есть письма, которое сам Фонд отправляет В Kaspi с
поручением перечислить деньги с эскроу-счёта ГП) — нет ни одного. Без
этого нельзя честно описать: одноязычный формат или двуязычный, структуру
блоков реквизитов, типографику (шрифт/кегль/жирность), число подписантов
на письме, наличие или отсутствие внутреннего контрольного блока «Принято
в работу...».

## Что делать при первом реальном запросе по Kaspi

1. Скажи пользователю прямо: формат письма по Kaspi не задокументирован,
   нужен реальный пример или пустой бланк банка.
2. Когда пример появится — заведи `references/kaspi/formatting-spec.md` по
   образцу уже существующих (`references/bck/formatting-spec.md`,
   `references/alatau/formatting-spec.md` и т.д.): извлекай типографику из
   XML документа, а не угадывай по картинке.
3. Реквизиты налогов/взносов (`references/shared/tax-beneficiaries.md`) и
   правило транзитных счетов (`references/shared/transit-accounts.md`) уже
   общие для всех банков — переиспользуй их, не переписывай заново.
4. Обнови таблицу в `SKILL.md` (Шаг 0 и Шаг 3), убрав пометку «не
   подтверждён» для Kaspi.
