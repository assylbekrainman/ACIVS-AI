# Формат письма — зависит от банка, НЕ единый бланк на всех

**Важная история этого файла.** В более ранней версии этого скилла
(`escrow-fot`, до слияния в единый параметризованный по банку скилл) здесь
было утверждение: «двуязычный бланк БЦК (`assets/bck/template-bck.docx`) —
универсальный стандарт для ВСЕХ банков», обоснованное тем, что норму о
двуязычных расписках ввело Постановление Правления НБ РК от 31.12.2025 №111
в целом, не только для операций через БЦК. На момент, когда это писалось,
это было разумной гипотезой (сам текст бланка нигде не называет БЦК по
имени) — но с тех пор появились реальные письма ещё по трём банкам, и они
**эту гипотезу не подтверждают**:

- **Alatau** — реальное письмо (август 2025) одноязычное (русский).
- **Forte** — реальное письмо (2026) одноязычное (русский), к тому же с
  собственной структурой подписей (три стороны на документе).
- **Freedom** — реальное подтверждающее письмо (август 2026) тоже
  одноязычное; двуязычный бланк здесь используется как основной ТОЛЬКО по
  прямому решению пользователя, а не потому что двуязычный формат — общая
  практика по всем банкам.

**Вывод: формат письма — не универсален, определяется конкретным банком.**
Единственный банк, для которого двуязычный бланк подтверждён как реальная
практика — БЦК. Актуальная типографика и структура для каждого банка — в
`references/<банк>/formatting-spec.md`:

| Банк | Формат | Файл |
|---|---|---|
| БЦК | Двуязычный бланк (KZ/RU колонки) | `references/bck/formatting-spec.md` |
| Alatau | Одноязычный (RU), простая структура | `references/alatau/formatting-spec.md` |
| Forte | Одноязычный (RU), 3 подписанта на письме | `references/forte/formatting-spec.md` |
| Freedom | Двуязычный официальный бланк банка (по решению пользователя) | `references/freedom/formatting-spec.md` |

Если появляется пятый банк без задокументированного формата — не выбирай
шаблон по аналогии молча; запроси у пользователя реальный пример письма или
пустой бланк этого банка и заведи для него новый раздел `references/<банк>/`
по этому же образцу (см. `SKILL.md`, раздел «Банк, которого здесь нет»).

Простые одноязычные письма БЦК (`assets/bck/example-simple-letter-jusan-2025.docx`)
— исторический пример до вступления нормы о двуязычных расписках в силу
(датирован февралём 2025), полезен только как источник формулировок и
реквизитов, не как альтернативный формат для БЦК сегодня. Если пользователь
прямо просит одноязычный вариант для БЦК или говорит, что для конкретного
ГП принят другой формат — следуй прямому указанию пользователя, оно всегда
сильнее этого файла.
