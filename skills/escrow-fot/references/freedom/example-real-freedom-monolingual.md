# Реальный пример: письмо по Freedom Bank (одноязычное, июнь 2026)

Источник: фото реального отправленного письма (4 страницы), проект ТОО
«Shaiyr Agro Group», Договор гранта №96 от 05.09.2024, эскроу-счёт
№ AST-ES-2024-00037 от 27.09.2024 (АО «Фридом Банк Казахстан», филиал в
г. Астана). Период: июнь 2026 г. Итоговая сумма 1 363 795,00 тенге — проверена
программно построчно по всем 8 категориям, расхождений нет (в отличие от
примера БЦК, где нашлась ошибка в казахской таблице по соцналогу — здесь
такой ошибки нет).

**НЕ основной формат для этого скилла.** По решению пользователя (11.08.2026)
основным форматом для Freedom остаётся официальный ДВУЯЗЫЧНЫЙ бланк
банка (`assets/freedom/template-freedom-blank.docx`), даже притом что это реальное
письмо — одноязычное (только русский текст, без казахской части вообще).
Это уже третий реальный пример подряд с одноязычным письмом (после Jusan-2025
и Forte-2026) — похоже, в реальной практике
двуязычный формат подтверждён только для БЦК. Используй этот файл ТОЛЬКО как
источник фактов и реквизитов (см. ниже), не как образец языковой структуры
письма — если пользователь явно не попросит одноязычный вариант для Freedom.

Важная оговорка по точности: источник — фотографии бумажного документа, не
чистый скан/докс. Номера счетов ниже перепечатаны из транскрипции фото и
могут содержать опечатки самого фотографирования/распознавания — там, где
значение совпадает с уже независимо проверенным (см. `references/shared/tax-beneficiaries.md`),
бери проверенное значение как основное, а не то, что перепечатано здесь.

## Новое наблюдение: счёт Казначейства для ИПН/Соцналог — один на всю страну

БИК (KKMFKZ2A) и ИИК (KZ24070105KSN0000000) для ИПН и Соцналога **совпадают**
между двумя разными районами из двух разных реальных писем: Бостандыкский
район г. Алматы (БИН УГД 910740000044, проект DP23692292) и Айыртауский район
Северо-Казахстанской области (БИН УГД 980740001302, этот пример). Похоже,
это ОДИН централизованный счёт Комитета казначейства МФ РК на всю страну —
меняется только БИН конкретного УГД (получателя-адресата), а не счёт, на
который физически приходят деньги. Если это подтвердится третьим примером —
можно считать БИК/ИИК для ИПН/Соцналог универсальными константами, а искать
заново нужно будет только БИН конкретного УГД по адресу ГП.

## Другие наблюдения из этого письма

- **Кбе 14 указан для зарплатного транзитного счёта** (Halyk Bank) — в
  бланке БЦК поле Кбе для зарплатных блоков вообще отсутствует (см.
  `references/bck/formatting-spec.md`), здесь оно есть и заполнено. Не факт, что 14 —
  universal для любого зарплатного транзитного счёта в любом банке; это
  просто первое реальное значение, которое встретилось. Не подставляй его
  как жёсткое правило без подтверждения.
- **Один сотрудник (Ляшенко И.И.) исключён из ОПВР** (48 125 = сумма по 4 из
  5 сотрудников) — та же картина, что и с пенсионерами в примере БЦК, хотя
  дата рождения (06.05.1971) не выглядит очевидно пенсионной — причина
  исключения не установлена, доверяй исходной РПВ/табелю, не пытайся
  угадать логику.
- Реквизиты Фонда науки в этом письме: ИИК KZ026017111000000822, БИК
  HSBKKZKX, АО «Народный Банк Казахстана», Кбе 16, БИН 061140001887,
  подписант — Управляющий директор Рахимжанов А.Б. — совпадает с самым
  свежим вариантом из `references/shared/fund-payer-details.md` (актуален на 2026 г.).
- Присутствует тот же блок «Принято в работу, сверка подписей и печатей
  Клиента...» (Менеджер/Начальник) — подтверждает, что это общая практика
  Фонда, а не специфика одного банка или одного скилла.
