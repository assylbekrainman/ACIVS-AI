# Типографика и структура — эталон «Эскроу-расписка» (ForteBank)

Извлечено из XML `assets/example-escrow-equipment-forte.docx`, реальная
расписка Фонда науки по статье «Закуп оборудования и(или) программного
обеспечения», проект ТОО «MNT Group» DP25900609, поставщик ТОО «Caspian
Qurylys Invest», сумма 36 680 000,00 тенге (предоплата 70%). Собран на базе
того же эталонного бланка Фонда науки, что и `escrow-payment-alatau`
(структура письма идентична — меняются только банк, реквизиты сторон и
текст абзаца-основания).

## Шрифт и кегль

- Шрифт — **Times New Roman**, задан явно почти на каждом ране.
- Кегль основного текста — 12pt практически везде.
- Нет таблиц — весь документ состоит из обычных абзацев (в отличие от
  зарплатных ФОТ-расписок escrow-fot, где таблицы обязательны).

## Структура письма построчно

1. Правый край, жирным: «В Филиал АО «ForteBank»».
2. Следующая строка, жирным: дата (««___» ________________ 20__ год») с
   табуляцией и городом справа (город — из адреса филиала банка/эскроу-счёта
   по Договору эскроу-счёта проекта, например «в г. Шымкент»; для проекта с
   другим филиалом ForteBank бери его город).
3. Пустая строка.
4. По центру, жирным: «Эскроу-расписка».
5. Пустая строка.
6. Абзац по ширине (отступ первой строки ≈0.5″): «В соответствии с
   Договором эскроу-счета № ‹номер› от ‹дата›, заключенного между
   АО «ForteBank» *(Получатель)* и АО «Фонд науки» *(Клиент)*,» — слова
   «Получатель» и «Клиент» в скобках курсивом. Если в Договоре
   эскроу-счёта конкретного проекта третьей стороной указан не сам ГП, а
   иное лицо (например вуз-заявитель), включи это лицо между банком и
   «(Получатель)» — сверь точную формулировку по самому договору эскроу.
7. Абзац по ширине: «в связи с оплатой статьи п.‹№› «‹название статьи›»,
   согласно Приложению 2 «Смета расходов» Договора о предоставлении гранта
   на коммерциализацию результатов научной и (или) научно-технической
   деятельности №‹номер› от ‹дата› г. просим вас разрешить оплату за
   ‹назначение› в размере ‹% или «окончательный расчёт»/«аванс»› согласно
   Договора ‹поставки/оказания услуг› №‹номер› от ‹дата›, осуществив
   перевод в сумме ‹цифрами›,00 (‹прописью›) тенге с эскроу счета
   №‹номер эскроу-счёта› для затрат по закупу ‹назначение› по следующим
   реквизитам:».
   **Важно:** доля/процент платежа и номер+дата договора с поставщиком —
   обязательная часть этого абзаца, бери их из письма-обоснования ГП или
   спецификации к договору поставки (условия оплаты) дословно по смыслу.
   Одной суммы без указания, какую часть договора она покрывает,
   недостаточно — расписку вернут на доработку. Валюта — «тенге» без «ң»
   (этот бланк одноязычный, без казахской версии).
8. Пустая строка.
9. Жирным: «Реквизиты получателя платежа:».
10. Жирным, отдельной строкой: наименование получателя (например «ТОО
    «Caspian Qurylys Invest»»).
11. Обычным текстом, каждая деталь на отдельной строке (без жирности):
    «Адрес: ‹адрес›», «БИН/ИИН ‹номер›», «ИИК ‹номер›», «АО «ForteBank»»
    (или «Филиал АО «ForteBank» в г. ‹город›», если так указано в
    исходных документах), «БИК ‹код›».
    **Отличие от эталона Alatau:** если в счёте на оплату/договоре
    поставщика явно указан Кбе получателя (частый случай для платежей в
    ForteBank), добавь отдельную строку «Кбе ‹код›» после БИК — без него
    платёжное поручение банка может быть неполным. В эталонном бланке
    Alatau такой строки нет, но это не значит, что её нужно опускать,
    если данные есть у тебя на входе.
12. Пустая строка.
13. Блок Фонда науки — весь блок сдвинут отступом (визуально выглядит как
    смещённый вправо блок, а не таблица):
    - «АО «Фонд науки»» — жирным.
    - «Адрес: г. Астана, пр. Тәуелсіздік, 41» — обычным.
    - «Тел: +7 (7172) 575 003» — обычным (актуальный номер, см.
      `known-notes.md`).
    - «БИН 061140001887» — обычным.
    - «ИИК ‹номер›» — обычным (см. `known-notes.md` про подтверждённый
      вариант).
    - «БИК HSBKKZKX» — обычным.
    - «АО «Народный Банк Казахстана»» — обычным.
    - «Кбе 16» — обычным.
14. Пустая строка/отступ.
15. Тот же левый отступ: должность жирным («Управляющий директор»), затем
    ФИО жирным с линией для подписи на той же строке, затем «М.П.»
    обычным шрифтом.
16. Пустая строка / горизонтальная черта.
17. Абзац по ширине: «Принято в работу, сверка подписей и печатей
    Плательщика с предоставленными документами образцов подписей и печатей
    осуществлена:».
18. «Менеджер» жирным + линия для подписи + линия для ФИО, ниже курсивом
    мелким шрифтом подписи «(подпись)» / «(ФИО)».
19. «Начальник» жирным + линия для подписи + линия для ФИО, аналогично.

## Что в этом бланке ОТСУТСТВУЕТ (в отличие от ФОТ-расписки escrow-fot)

- Нет таблиц вообще — все реквизиты построчно.
- Нет казахской версии текста.
- Нет разбивки на 8 категорий — один получатель, один платёж.

## Практический способ собрать документ

Не печатай XML руками — открой `assets/example-escrow-equipment-forte.docx`
через python-docx, замени текст внутри существующих runs соответствующих
абзацев (сохраняя bold/italic/шрифт), а не пересобирай документ с нуля —
так гарантированно сохранится точная типографика эталона. При необходимости
вставить новую строку (например «Кбе ‹код›» получателя, если её нет в
эталоне) — скопируй `deepcopy` соседнего абзаца с похожим форматированием
(например БИК) и вставь через `addnext`, затем замени текст в скопированном
абзаце.
