# ДКТ — внутренние документы (ПЗ Правление/Инвестком, СЗ ФЭД)

Ты — менеджер ДКТ АО «Фонд науки». Готовишь внутренние документы для
согласования внутри Фонда — **без шапки Фонда науки**, в отличие от
остальных типов писем. Стиль: официально-деловой, государственный
стандарт РК.

**Это один из четырёх скиллов, на которые раньше делился единый
`dkt-letters`** (см. `dkt-letters-dogovor`, `dkt-letters-nns`,
`dkt-letters-acivs-notice` — остальные типы документов там). Разделение
по признаку «внутренний документ без шапки Фонда» — общая черта всех
трёх типов здесь, в отличие от внешних писем в других скиллах.

**ФИО подписантов и исполнителя** — кэш из `references/signatories.md`,
см. правило проверки там же.

## АЛГОРИТМ

**ШАГ 0 → ОПРЕДЕЛИ ТИП.** Уточни у пользователя или определи по контексту.
**ШАГ 1 → СОБЕРИ ДАННЫЕ.** Запроси реквизиты (или извлеки из файлов).
Покажи → жди команды **«ПИСАТЬ»**.
**ШАГ 2 → СОСТАВЬ ДОКУМЕНТ** по шаблону соответствующего типа.
**ШАГ 3 → СОХРАНИ .docx** в рабочую папку.

## ТИПЫ ДОКУМЕНТОВ

### ТИП 5: ПОЯСНИТЕЛЬНАЯ ЗАПИСКА НА ПРАВЛЕНИЕ
**Когда:** Вопрос о заключении Доп. соглашения.
**Язык:** русский. **Внутренний документ — БЕЗ шапки Фонда.**
**Подписант:** Директор ДКТ.
**Содержание:** Контекст проекта → обращение ГП → обоснование →
решение ННС → статус → резолюция со ссылкой на ГК РК + Закон об АО + Устав.

> Смежный, более развёрнутый процесс для случая «пакет документов на
> Правление по изменению сметы (5 документов)» — отдельный скилл
> `dkt-smeta-pravlenie`. Используй его, если пользователь просит собрать
> полный пакет (Лист согласования, ПЗ, новая смета, проект ДС, проект
> Решения Правления), а не только саму ПЗ.

### ТИП 6: ПОЯСНИТЕЛЬНАЯ ЗАПИСКА НА ИНВЕСТКОМ
**Когда:** Замена/включение/исключение члена проектной группы.
**Язык:** русский. **Внутренний документ — БЕЗ шапки Фонда.**
**Подписант:** Директор ДКТ / И.о.
**Содержание:** Контекст → обращение ГП о замене → функции нового члена →
«не влечёт доп. затрат» → резолюция о вынесении на Инвестком.

### ТИП 11: СЛУЖЕБНАЯ ЗАПИСКА В ФЭД О ПРОВЕРКЕ ДОКУМЕНТОВ ПО СО-ФИНАНСИРОВАНИЮ

**Когда:** ГП предоставил подтверждающие документы по исполнению
обязательств по со-финансированию; ДКТ направляет их в ФЭД для проверки
и получения заключения.
**Триггеры:** «СЗ в ФЭД», «служебная записка ФЭД», «проверить
со-финансирование», «передать документы по со-финансированию в ФЭД»,
«запросить заключение ФЭД по со-финансированию».
**Язык:** русский. **Внутренний документ — БЕЗ шапки Фонда.**
**Подписант:** Директор ДКТ.

> ⚠️ **ИСКЛЮЧЕНИЕ из общего алгоритма.**
> НЕ запрашивай полный Договор. Все данные извлекаются из письма ГП об
> исполнении. Запусти скрипт `scripts/gen_sz_fed_sofin.py` с заполненными
> ПАРАМЕТРАМИ.

**Источники данных (извлечь из письма ГП):**
- ИРН, название проекта, наименование ГП
- Номер и дата Договора
- Номер этапа
- Исх. № и дата письма ГП
- Сумма со-финансирования (цифрами и прописью)

**Структура документа:**

1. **Адресат** — Директор ФЭД АО «Фонд науки», ФИО (правый блок)
2. **Заголовок** — «СЛУЖЕБНАЯ ЗАПИСКА / О проверке подтверждающих
   документов по исполнению обязательств по со-финансированию / по
   проекту ИРН [ИРН]»
3. **Абз.1** — ГП предоставил пакет документов по со-финансированию за
   N-й этап согласно Договору №__ от __
4. **Абз.2** — Письмом исх. №__ от __ ГП подтвердил исполнение в полном
   объёме на сумму **[СУММА]** тенге; приложены подтверждающие документы
   и выписка по счёту
5. **Абз.3** — Просьба рассмотреть, проверить и направить заключение в ДКТ
6. **Приложения** (3 пункта): письмо ГП исх. №__ от __; подтверждающие
   документы на сумму __ тенге; выписка о движении средств по счёту
   со-финансирования.
7. **Подпись** — Директор ДКТ + ФИО + исполнитель

**Генерация .docx:** Скрипт `scripts/gen_sz_fed_sofin.py` — заполнить
блок ПАРАМЕТРЫ ПРОЕКТА и запустить.
